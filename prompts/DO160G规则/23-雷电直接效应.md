# DO-160G 第23章 雷电直接效应 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到雷电/闪电直接效应章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-23-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有名称和型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号判 Fail，并逐台列出缺失项。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-23-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 将所需功能与设备清单逐项对应；缺少完成任一必需功能的设备，或设备清单与程序明显不一致，判 Fail，并说明缺少的设备功能。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-23-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 比对设备参数与本章试验范围、载荷量级和允许误差。量程或频率范围不能覆盖试验要求、精度不能满足试验允差，判 Fail，并列出“设备能力—本章要求”的差异。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 参数因图表不可读或解析缺失而无法确认时判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-23-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出校准周期、有效期或可核验的校准状态；完全缺失判 Fail。
2. 核查是否明确要求试验实施时设备处于校准有效期内；只列周期但未约束试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-23-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 宜要求在试验记录中写明替代设备、替代理由和能力对比；存在替代条款但无记录要求判 Review。

## 06. 雷电直接效应 四字符类别标识

- 规则编号：QTP-DO160G-23-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：本章类别由 4 个字符组成，前 2 位为高压雷击附着试验类别，后 2 位为大电流物理破坏试验类别，且必须与设备所在雷击区域一致。

### 审查内容

核查四字符类别标识的完整性与其和雷击区域的对应关系。

### 审查步骤

1. 核查标识位数与结构。**设备的类别符号由 4 个字符组成——前 2 个字符表示高压雷击附着试验类别，第 3 和第 4 个字符表示大电流物理破坏试验类别**（例如 2A2A）。标识不足 4 位判 Fail。
2. 核查未做试验的标识方式。**不进行高压雷击附着试验时前 2 个字符应为 XX；不进行大电流物理破坏试验时第 3、4 个字符应为 XX；不进行任何试验时类别符号应为 XXXX**。类别位非 XX 却未安排对应试验判 Fail；标为 XX 却安排了该试验判 Review。
3. 核查非标准波形的标识与说明义务。**若高压或大电流试验所用的波形或试验配置与本章规定不同，则使用类别符号 ZZ**（例如非标准波形高压试验 + 1A 类大电流试验记为 **ZZ1A**）；**当使用 ZZ 时，试验报告中应描述具体的试验条件和试验电平**。使用 ZZ 却无具体条件与电平描述判 Fail。
4. 核查类别与雷击区域一致。**指定的设备试验类别应与设备所在的雷击区域一致**。文档未说明设备所处雷击区域判 Fail（无区域则类别无从核验）。

## 07. 雷击区域与类别语义

- 规则编号：QTP-DO160G-23-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查所声明类别的区域定义与设备安装位置描述是否吻合。

### 审查内容

核查所声明类别的区域定义与设备安装位置描述是否吻合。

### 审查步骤

1. 核对 1 区类别。**1A 类**——位于雷击区域 1A 的外部安装设备，区域 1A 指飞机表面上**首次回击可能发生在雷电通道附着时并伴有低预期闪光拖延**的区域；**1B 类**——区域 1B 指**首次回击并伴有高预期闪光拖延**的区域；**1C 类**——区域 1C 指**幅度降低以后的首次回击**并伴有低预期闪光拖延的区域。所声明类别与文档描述的区域特征不符判 Fail。
2. 核对 2 区类别。**2A 类**——区域 2A 指**连续回击以低预期闪光拖延进行扫掠**的区域；**2B 类**——区域 2B 指**连续回击的雷电通道以高预期闪光拖延进行扫掠**的区域。类别与区域描述不符判 Fail。
3. 核对 3 区类别。**3N 类**——位于雷击区域 3 的外部安装设备，区域 3 具有**能明显降低由传统设计得到的防护等级的新设计特点**，或**尚无任何被证实的维修史**。声明 3N 却未说明属于上述哪种情形判 Review。
4. 核查适用性前提。本章类别针对**外部安装设备**。设备为内部安装却安排了雷电直接效应试验，判 Review（应说明依据）；外部安装设备却标为 XXXX 且无豁免说明，判 Fail。

## 08. 高压雷击附着试验

- 规则编号：QTP-DO160G-23-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查高压试验的类型选择、波形取值与试验目的对应。

### 审查内容

核查高压试验的类型选择、波形取值与试验目的对应。

### 审查步骤

1. 核查试验目的表述。**高压试验用于确定雷电在设备上可能的附着位置，并验证非导电材料保护措施的充分性**。文档把高压试验的目的写成「验证耐受电流能力」判 Fail（那是大电流试验的目的）。
2. 核对试验类型。标准定义两类高压试验：**初始先导附着试验**——用于确定接近的雷电先导在设备某块区域可能产生的附着位置；**扫掠通道附着试验**——用于确定雷电通道掠过设备时可能产生的附着位置。**对试验件进行的高压试验类型取决于其试验类别要求**。所选试验类型与类别不匹配判 Fail；未说明所做的是哪一类判 Fail。
3. 核对高压波形取值。标准列出了各试验类别对应的试验类型与**高压波形（A 或 D）**。例如 **1A、1B 类的初始先导附着试验使用波形 D**。所用波形与本类别在的规定不符判 Fail，并写明应为多少、实为多少；仅写「按」而无具体波形判 Fail。
4. 核查附着点的记录要求。高压试验的产出是**可能的雷电附着位置**，应规定附着点的观察与记录方式。未规定判 Fail（无附着点记录则后续大电流试验的施加位置无依据）。
5. 核查非导电材料保护的验证。高压试验还用于**验证非导电材料保护措施的充分性**。设备含非导电外表面却未涉及该项验证，判 Review。

## 09. 大电流物理破坏试验

- 规则编号：QTP-DO160G-23-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查大电流试验的目的、电流分量与施加位置。

### 审查内容

核查大电流试验的目的、电流分量与施加位置。

### 审查步骤

1. 核查试验目的表述。**大电流破坏试验用于验证设备耐受雷电电流的能力**。目的表述与高压试验混淆判 Fail。
2. 核对电流分量与波形。大电流试验按类别施加规定的电流分量（如 A、B、C、D 分量）及其幅值、作用积分与电荷转移量。文档未给出所施加的电流分量及其具体参数判 Fail；参数与所声明类别（第 3、4 位）对应的规定不符判 Fail。
3. 核查施加位置。大电流应施加在高压试验确定的**附着位置**上。未说明施加位置的确定依据判 Fail。
4. 核查破坏判据的观察项。大电流试验关注**烧蚀、穿孔、变形、结构强度损失**等物理破坏。判据完全不涉及物理破坏形态判 Fail。

## 10. 试验安全与判据

- 规则编号：QTP-DO160G-23-10
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查试验实施条件、人员资质要求与合格判据。

### 审查内容

核查试验实施条件、人员资质要求与合格判据。

### 审查步骤

1. 核查试验实施条件。雷电模拟试验需要高能量电气设备，工作期间可能充电至很高电压；**所有试验应在受控区域并由具备高压/大电流试验经验的人员实施**，应遵守相关安全措施。未说明试验场所与人员资质要求判 Review。
2. 核查合格判据的覆盖面。判据应同时覆盖**物理破坏**（烧蚀、穿孔、变形、结构完整性）与**功能符合性**（试验后设备是否仍满足性能规范）。只涉及其一判 Fail。
3. 核查 ZZ 标识情形的说明义务。使用 ZZ 时**试验报告中应描述具体的试验条件和试验电平**。使用 ZZ 却无描述判 Fail。
4. 核查判据可判定性。仅写「符合 DO-160G 标准」而无具体判定项判 Review；完全未给判据判 Fail。
5. 核查偏离说明。存在与本章规定的偏离（波形、类别、施加位置）却无说明判 Fail。
