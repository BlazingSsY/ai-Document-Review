# DO-160G 第23章 雷电直接效应 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到雷电/闪电直接效应章。

---

## 1. 雷电直接效应 四字符类别标识

- 规则编号：QTP-DO160G-23-A
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：本章类别由 4 个字符组成，前 2 位为高压雷击附着试验类别，后 2 位为大电流物理破坏试验类别，且必须与设备所在雷击区域一致。

### 审查内容

核查四字符类别标识的完整性与其和雷击区域的对应关系。

### 审查步骤

1. 核查标识位数与结构。**设备的类别符号由 4 个字符组成——前 2 个字符表示高压雷击附着试验类别，第 3 和第 4 个字符表示大电流物理破坏试验类别**（例如 2A2A）。标识不足 4 位判 Fail。
2. 核查未做试验的标识方式。**不进行高压雷击附着试验时前 2 个字符应为 XX；不进行大电流物理破坏试验时第 3、4 个字符应为 XX；不进行任何试验时类别符号应为 XXXX**。类别位非 XX 却未安排对应试验判 Fail；标为 XX 却安排了该试验判 Review。
3. 核查非标准波形的标识与说明义务。**若高压或大电流试验所用的波形或试验配置与本章规定不同，则使用类别符号 ZZ**（例如非标准波形高压试验 + 1A 类大电流试验记为 **ZZ1A**）；**当使用 ZZ 时，试验报告中应描述具体的试验条件和试验电平**。使用 ZZ 却无具体条件与电平描述判 Fail。
4. 核查类别与雷击区域一致。**指定的设备试验类别应与设备所在的雷击区域一致**。文档未说明设备所处雷击区域判 Fail（无区域则类别无从核验）。

## 2. 雷击区域与类别语义

- 规则编号：QTP-DO160G-23-B
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查所声明类别的区域定义与设备安装位置描述是否吻合。

### 审查内容

核查所声明类别的区域定义与设备安装位置描述是否吻合。

### 审查步骤

1. 核对 1 区类别。**1A 类**——位于雷击区域 1A 的外部安装设备，区域 1A 指飞机表面上**首次回击可能发生在雷电通道附着时并伴有低预期闪光拖延**的区域；**1B 类**——区域 1B 指**首次回击并伴有高预期闪光拖延**的区域；**1C 类**——区域 1C 指**幅度降低以后的首次回击**并伴有低预期闪光拖延的区域。所声明类别与文档描述的区域特征不符判 Fail。
2. 核对 2 区类别。**2A 类**——区域 2A 指**连续回击以低预期闪光拖延进行扫掠**的区域；**2B 类**——区域 2B 指**连续回击的雷电通道以高预期闪光拖延进行扫掠**的区域。类别与区域描述不符判 Fail。
3. 核对 3 区类别。**3N 类**——位于雷击区域 3 的外部安装设备，区域 3 具有**能明显降低由传统设计得到的防护等级的新设计特点**，或**尚无任何被证实的维修史**。声明 3N 却未说明属于上述哪种情形判 Review。
4. 核查适用性前提。本章类别针对**外部安装设备**。设备为内部安装却安排了雷电直接效应试验，判 Review（应说明依据）；外部安装设备却标为 XXXX 且无豁免说明，判 Fail。

## 3. 高压雷击附着试验

- 规则编号：QTP-DO160G-23-C
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查高压试验的类型选择、波形取值与试验目的对应。

### 审查内容

核查高压试验的类型选择、波形取值与试验目的对应。

### 审查步骤

1. 核查试验目的表述。**高压试验用于确定雷电在设备上可能的附着位置，并验证非导电材料保护措施的充分性**。文档把高压试验的目的写成「验证耐受电流能力」判 Fail（那是大电流试验的目的）。
2. 核对试验类型。标准定义两类高压试验：**初始先导附着试验**——用于确定接近的雷电先导在设备某块区域可能产生的附着位置；**扫掠通道附着试验**——用于确定雷电通道掠过设备时可能产生的附着位置。**对试验件进行的高压试验类型取决于其试验类别要求**。所选试验类型与类别不匹配判 Fail；未说明所做的是哪一类判 Fail。
3. 核对高压波形取值。标准列出了各试验类别对应的试验类型与**高压波形（A 或 D）**。例如 **1A、1B 类的初始先导附着试验使用波形 D**。所用波形与本类别在的规定不符判 Fail，并写明应为多少、实为多少；仅写「按」而无具体波形判 Fail。
4. 核查附着点的记录要求。高压试验的产出是**可能的雷电附着位置**，应规定附着点的观察与记录方式。未规定判 Fail（无附着点记录则后续大电流试验的施加位置无依据）。
5. 核查非导电材料保护的验证。高压试验还用于**验证非导电材料保护措施的充分性**。设备含非导电外表面却未涉及该项验证，判 Review。

## 4. 大电流物理破坏试验

- 规则编号：QTP-DO160G-23-D
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查大电流试验的目的、电流分量与施加位置。

### 审查内容

核查大电流试验的目的、电流分量与施加位置。

### 审查步骤

1. 核查试验目的表述。**大电流破坏试验用于验证设备耐受雷电电流的能力**。目的表述与高压试验混淆判 Fail。
2. 核对电流分量与波形。大电流试验按类别施加规定的电流分量（如 A、B、C、D 分量）及其幅值、作用积分与电荷转移量。文档未给出所施加的电流分量及其具体参数判 Fail；参数与所声明类别（第 3、4 位）对应的规定不符判 Fail。
3. 核查施加位置。大电流应施加在高压试验确定的**附着位置**上。未说明施加位置的确定依据判 Fail。
4. 核查破坏判据的观察项。大电流试验关注**烧蚀、穿孔、变形、结构强度损失**等物理破坏。判据完全不涉及物理破坏形态判 Fail。

## 5. 试验安全与判据

- 规则编号：QTP-DO160G-23-E
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：雷电直接效应,闪电直接效应
- 规则说明：核查试验实施条件、人员资质要求与合格判据。

### 审查内容

核查试验实施条件、人员资质要求与合格判据。

### 审查步骤

1. 核查试验实施条件。雷电模拟试验需要高能量电气设备，工作期间可能充电至很高电压；**所有试验应在受控区域并由具备高压/大电流试验经验的人员实施**，应遵守相关安全措施。未说明试验场所与人员资质要求判 Review。
2. 核查合格判据的覆盖面。判据应同时覆盖**物理破坏**（烧蚀、穿孔、变形、结构完整性）与**功能符合性**（试验后设备是否仍满足性能规范）。只涉及其一判 Fail。
3. 核查 ZZ 标识情形的说明义务。使用 ZZ 时**试验报告中应描述具体的试验条件和试验电平**。使用 ZZ 却无描述判 Fail。
4. 核查判据可判定性。仅写「符合 DO-160G 标准」而无具体判定项判 Review；完全未给判据判 Fail。
5. 核查偏离说明。存在与本章规定的偏离（波形、类别、施加位置）却无说明判 Fail。
