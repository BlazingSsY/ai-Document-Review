## 1. 结冰试验 鉴定类别声明

- 规则编号：QTP-DO160G-24-A
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：结冰类别（A/B/C）决定试验程序与循环数。与温度－高度试验的设备类别是两套体系。

### 审查内容

核查是否声明结冰类别，且类别与设备特征、安装位置相符。

### 审查步骤

1. 查找类别代号。标准规定三类：**A类**——安装在飞机外部或非控温区，冷浸后遇高于冰点的潮湿空气产生冷凝而形成冰或霜；**B类**——装有活动部件、其活动可能受结冰影响或阻碍、或因冰膨胀使结构/功能部件受损的设备；**C类**——安装在飞机外部或非控温区、有积累自由水危险、自由水随后在冷表面结冰的设备。未声明类别判 Fail。
2. 核查类别与设备特征是否自洽。设备含活动部件且可能被冰阻碍却未选 B 类，或无自由水积累风险却选 C 类，判 Fail；未说明安装位置与设备特征判 Review。
3. 核查 C 类的冰厚要求来源。C 类**要求的冰的厚度和分布，以及有关冰逐渐形成的任何要求，应在有关设备性能标准中规定**。声明 C 类却未给出冰厚要求及其出处，判 Fail。

## 2. 结冰试验通用准备

- 规则编号：QTP-DO160G-24-B
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：核查安装方式、表面清洁与发热设备工作时间限制。

### 审查内容

核查安装方式、表面清洁与发热设备工作时间限制。

### 审查步骤

1. 核查安装方式。按**能代表飞机上正常安装的方式**安装受试设备。未说明安装方式判 Review。
2. 核查表面清洁要求。开始试验前应**去除所有非典型污染物（如油、油脂和污垢）**，因其会影响冰与设备表面间的附着作用。缺该要求判 Fail（污染物会直接影响结冰效果，属试验有效性前提）。
3. 核查发热设备的工作限制。**发热设备的工作时间应仅限于确定符合性所需的时间内**。设备发热却要求全程通电判 Fail；未说明判 Review。

## 3. A 类结冰试验程序

- 规则编号：QTP-DO160G-24-C
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：核查 A 类的温湿度条件、循环数与最终判定条件。

### 审查内容

核查 A 类的温湿度条件、循环数与最终判定条件。

### 审查步骤

1. 核对初始稳定温度。设备**不工作**，在试验室压力和湿度条件下将设备温度稳定在**规定的地面低温耐受温度**（除 A4/B3/C3 为注(3)外，其余类别均为 **-55℃**）。温度未取地面耐受低温判 Fail。
2. 核对暖湿暴露条件。24.4.2b/c：尽快将设备暴露于**温度 30℃、相对湿度至少 95%** 的环境；**在设备表面温度达到 5℃ 前**保持箱内 30℃ 与至少 95% RH，然后尽快将箱温降回地面低温耐受温度。温湿度不符判 Fail；缺「表面温度达到 5℃ 前」这一判定点判 Fail。
3. 核对循环数。重复步骤 a~c 两个循环，**总计 3 个循环**。循环数不足 3 个判 Fail（检查单同样要求「循环次数足够 3 次」）。
4. 核对最终判定条件。第三个循环结束时将设备温度稳定在地面低温耐受温度；**升高并保持试验箱温度到 -10℃**，允许设备表面温度升高；**当表面温度达到 -10±5℃ 时使设备进入工作状态**，确定性能符合性。缺 -10℃ 箱温或 -10±5℃ 表面温度触发条件判 Fail。
5. 核查双试验箱建议。本试验使设备交替暴露于干冷和暖湿环境，**建议使用模拟这两种环境的两个不同试验箱**。使用单箱而未说明如何满足快速转换要求判 Review。

## 4. B 类结冰试验程序

- 规则编号：QTP-DO160G-24-D
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：核查 B 类的温度压力条件、升温速率、循环数与中断规定。

### 审查内容

核查 B 类的温度压力条件、升温速率、循环数与中断规定。

### 审查步骤

1. 核对初始条件。设备**不工作**，在试验室压力条件下将设备温度稳定在 **-20℃**；保持此温度并将试验箱压力降到**规定的相应最高工作高度**；**保持此条件至少 10 分钟**。温度、压力或时长不符判 Fail。高度：A类=15000ft、B类=25000ft、C类=35000ft、D类=50000ft、E类=70000ft、F类=55000ft。
2. 核对升温与增湿条件。以**不超过 3℃/min 的速率**升高箱温，同时升高并保持箱内**相对湿度不小于 95%**；保持足够时间使所有霜和冰融化，或直到**设备表面温度达到 0℃~5℃ 之间**；**此步骤期间任何时间内箱温不允许超过 30℃**。升温速率超 3℃/min、湿度不足、或箱温超 30℃，判 Fail。
3. 核对恢复压力过程。**在 15～30min 时间内以均匀速率**将箱压升高到室内环境压力；压力恢复完成后将箱内相对湿度降到室内正常环境。时间窗不符判 Fail。
4. 核对循环数。重复步骤 a~c，**总共完成 25 个循环或按有关设备规范的规定，以少者为准**。循环数多于 25 且无规范依据判 Review；少于 25 而未援引设备规范判 Fail（检查单同样要求「循环次数足够 25 次」）。
5. 核查中断规定。**如必须中断试验程序，应在设备处于低温条件时中断**。文档规定在暖湿阶段中断判 Fail；未说明判 Review。
6. 核对最终判定。最后一个循环结束、设备温度稳定在 **-20℃** 之后，确定性能符合性。判定温度不符判 Fail。

## 5. C 类结冰试验程序

- 规则编号：QTP-DO160G-24-E
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：核查冰的形态要求、结冰温度、喷水方式与判定条件。

### 审查内容

核查冰的形态要求、结冰温度、喷水方式与判定条件。

### 审查步骤

1. 核对冰的形态要求。形成的冰**应为透明而坚硬的（光亮的冰）**，**"白色"或带气穴的冰（霜冰）是不认可的**。文档未明确要求透明坚硬冰判 Fail（检查单同样要求「试验设备需要形成透明且硬的冰」）。
2. 核查结冰温度的确定方式。设备不工作，将设备温度稳定在**喷水时能在设备上结成透明坚硬冰的温度**；注2：**最佳温度可能在 -1℃ 和 -10℃ 之间**，具体取决于设备热质量，**此温度最好通过试验确定**。给出的温度落在 -1℃~-10℃ 之外且无试验依据，判 Fail；未说明温度确定方式判 Review。
3. 核对喷水方式与冰厚。**人工喷洒接近于冻结温度的细雾状水**，积累起有关设备性能标准规定厚度的**透明坚硬均匀冰层**。未说明喷水方式或冰厚要求判 Fail。
4. 核对判定条件。冰层达到要求厚度时停止喷洒，**使设备进入工作状态并将设备温度稳定在 -20℃**，再确定性能符合性。判定温度不符判 Fail。
5. 核查多厚度试验安排。若为增加冰厚需多次试验，应以**每一厚度量级连续形成**的方式进行一系列单独试验。安排多厚度但描述为一次连续加厚判 Review。

## 6. 结冰试验判据

- 规则编号：QTP-DO160G-24-F
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：结冰,积冰
- 规则说明：对应各程序末尾的性能确认要求与检查单「合格判据」条目。

### 审查内容

核查合格判据是否可判定并与所选类别的判定时机一致。

### 审查步骤

1. 核查判据可判定性。仅写「符合设备性能标准」而无具体判定项判 Review；完全未给判据判 Fail。
2. 核查判定时机与类别匹配。A 类在表面温度达 -10±5℃ 通电后判定；B 类在最后循环、温度稳定于 -20℃ 后判定；C 类在冰层达标、设备通电并稳定于 -20℃ 后判定。判定时机与所选类别不符判 Fail。
3. 核查 B 类的活动部件判据。B 类针对活动部件受冰阻碍或冰膨胀致损的情形，判据应覆盖**活动部件功能与结构完整性**。B 类判据完全不涉及活动部件判 Fail。
