# DO-160G 第25章 静电放电（ESD） 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到静电放电章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-25-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有名称和型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号判 Fail，并逐台列出缺失项。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-25-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 将所需功能与设备清单逐项对应；缺少完成任一必需功能的设备，或设备清单与程序明显不一致，判 Fail，并说明缺少的设备功能。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-25-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 比对设备参数与本章试验范围、载荷量级和允许误差。量程或频率范围不能覆盖试验要求、精度不能满足试验允差，判 Fail，并列出“设备能力—本章要求”的差异。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 参数因图表不可读或解析缺失而无法确认时判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-25-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出校准周期、有效期或可核验的校准状态；完全缺失判 Fail。
2. 核查是否明确要求试验实施时设备处于校准有效期内；只列周期但未约束试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-25-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 宜要求在试验记录中写明替代设备、替代理由和能力对比；存在替代条款但无记录要求判 Review。

## 06. 静电放电 适用范围与设备分类

- 规则编号：QTP-DO160G-25-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查类别声明与试验适用范围的界定。

### 审查内容

核查类别声明与试验适用范围的界定。

### 审查步骤

1. 核查类别声明。**A 类**——飞机正常操作和/或维修期间安装或运行的电子设备。未声明类别判 Fail。
2. 核对适用范围。本试验适用于**飞机正常操作和（或）维护过程中可接触到的所有设备和表面**；**本试验不适用于连接器针脚**。文档把连接器针脚列入试验点判 Fail；适用范围写成「全部外表面」而未限定于人员可接触部位判 Review。
3. 核查试验目的的表述。考核设备**在执行预期功能时不会因空气释放的静电脉冲而产生永久性性能降级**的能力。判据后续应与此对应。

## 07. ESD 发生器与试验配置

- 规则编号：QTP-DO160G-25-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查发生器电路参数、脉冲幅度、校准要求与安装接地方式。

### 审查内容

核查发生器电路参数、脉冲幅度、校准要求与安装接地方式。

### 审查步骤

1. 核对发生器电路参数。ESD 发生器应包括一个 **330Ω（±20%）的放电电阻器**和一个 **150pF（±20%）的储能电容器**，并应能生成 **15kV** 电压的正、负极性脉冲，且具有**所示的空气放电端**。参数不符判 Fail，并写明应为多少、实为多少；未写明判 Fail。
2. 核对校准要求。ESD **须校准输出的正负极性 15kV（+10%，-0%）脉冲峰值**，并应**记录输出此脉冲时 ESD 发生器的设置**。缺校准要求判 Fail；容差写成 ±10%（允许低于 15kV）判 Fail —— 标准只允许正偏差。
3. 核查安装与接地。受试设备应按 **20.3a（通用试验要求）**所述进行安装，根据相应安装和接口控制图连接放置；应特别注意**与 ESD 发生器相连电缆的布线和接地**，以减小电缆辐射场产生的二次影响。未说明安装与接地方式判 Fail。
4. 核对放电回路电缆的隔离距离。发生器的放电回路电缆应**通过接地平板接地**，并与 **EUT 及其电缆保持至少 0.2 米的距离**。距离不符或未写明判 Fail。
5. 核查监控设备的去耦。如需监控设备，为减少错误的故障指示，**应将监控设备去耦**。安排了过程监控却未提去耦判 Review。

## 08. 试验点选择与脉冲施加

- 规则编号：QTP-DO160G-25-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查试验点范围、脉冲数量与极性、放电手法与无放电时的处置。

### 审查内容

核查试验点范围、脉冲数量与极性、放电手法与无放电时的处置。

### 审查步骤

1. 核查试验点范围。试验点应包括**控制区域或键盘区域上的任何导电或非导电点**，以及人员接触的任何其他点，例如**开关、旋钮、按钮、指示器、LED、缝隙、格栅、连接器外壳**及其他操作人员能接触到的区域。试验点仅限于金属外壳而未覆盖非导电点、缝隙、格栅等判 Fail。
2. 核对脉冲数量与极性。在**每一个所选位置**上施加的正、负电压脉冲数量应**分别为 10 次（10 次正极和 10 次负极）**，幅度 **15kV**。次数或极性不符判 Fail，并写明应为多少、实为多少。
3. 核对施加限定。ESD 放电**仅用于正常操作（包括实际飞机安装和维护）过程中人员能够触及的点和面**；将发生器设在校准时记录的数值上，并**保持 ESD 发生器垂直于施加放电的表面**。缺「垂直于放电表面」判 Review；对人员不可触及部位施加放电判 Fail。
4. 核查放电手法。以**人手靠近触摸物体的速度（约 0.3 m/s）**将放电极移向测试点，直到发生器放电或接触到试验点；**每次放电或尝试放电之后，放电电极都应从测试点移开，然后再充电以完成下一次放电**。移动速度不符或未写明判 Review；缺「每次放电后移开再充电」判 Fail（连续放电会改变实际施加能量）。
5. 核查无放电情形的处置。在选取测试点无放电的情形，应**尝试在测试点周围区域找出放电点**，例如沿接缝或开槽截面多点放电、围绕按钮所有侧面放电以识别单一测试点。未规定无放电时的处置判 Review。
6. 核查工作模式覆盖。EUT 试验模式应包括**软件可选的 EUT 所有的正常工作模式**。仅测单一模式而未说明理由判 Fail。

## 09. 静电放电试验判据

- 规则编号：QTP-DO160G-25-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：静电放电
- 规则说明：核查判据是否落到「无永久性性能降级」，以及判定时机。

### 审查内容

核查判据是否落到「无永久性性能降级」，以及判定时机。

### 审查步骤

1. 核查判据内容。本试验考核设备在执行预期功能时**不会因空气释放的静电脉冲而产生永久性性能降级**的能力。判据应体现「不允许永久性性能降级」；判据只写「工作正常」而未区分瞬时扰动与永久降级，判 Review。
2. 核对判定时机。如无其它特殊规定，**施加脉冲之后**确定与适用设备性能规范的符合性。未说明判定时机判 Review。
3. 核查判据可判定性。仅写「符合 DO-160G 标准」而无具体判定项判 Review；完全未给判据判 Fail。
4. 核查试验环境因素的说明。影响 ESD 现象的因素包括低相对湿度、温度、低电导率地毯、乙烯基塑料座椅等。文档若完全未说明试验时的温湿度环境，判 Review（湿度直接影响放电效果）。
