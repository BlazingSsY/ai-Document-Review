# DO-160G 第17章 电压尖峰 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到电压尖峰章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-17-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有名称和型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号判 Fail，并逐台列出缺失项。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-17-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 将所需功能与设备清单逐项对应；缺少完成任一必需功能的设备，或设备清单与程序明显不一致，判 Fail，并说明缺少的设备功能。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-17-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 比对设备参数与本章试验范围、载荷量级和允许误差。量程或频率范围不能覆盖试验要求、精度不能满足试验允差，判 Fail，并列出“设备能力—本章要求”的差异。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 参数因图表不可读或解析缺失而无法确认时判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-17-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出校准周期、有效期或可核验的校准状态；完全缺失判 Fail。
2. 核查是否明确要求试验实施时设备处于校准有效期内；只列周期但未约束试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-17-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 宜要求在试验记录中写明替代设备、替代理由和能力对比；存在替代条款但无记录要求判 Review。

## 06. 电压尖峰 设备分类与供电说明

- 规则编号：QTP-DO160G-17-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查设备类别声明与供电参数说明。

### 审查内容

核查设备类别声明与供电参数说明。

### 审查步骤

1. 核查类别声明。标准 规定两类：**A类**——预期主要安装在为防止电压尖峰破坏**必需进行严格保护**场合的设备；**B类**——预期主要安装在**允许较低程度保护**场合的设备。未声明类别判 Fail。
2. 核查供电说明。检查单条目：应**明确供电说明（供电为 __ VDC/VAC）**。未写明供电电压与制式判 Fail。
3. 核查试验布置。检查单条目：应**具备图示和（或）文字描述的试验布置要求**。DO-160G 给出两种布置：**用于直流或单相交流供电设备，用于三相交流供电设备**。缺布置描述判 Fail；布置与供电制式不匹配（如三相设备用布置）判 Fail。

## 07. 尖峰波形与试验装置

- 规则编号：QTP-DO160G-17-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查瞬态波形参数、信号源阻抗与波形验证要求。

### 审查内容

核查瞬态波形参数、信号源阻抗与波形验证要求。

### 审查步骤

1. 核查波形要求。瞬态信号发生器应能产生**所示波形**；可使用其它产生尖峰信号的方法，**但波形需满足要求**。注：若波形的**脉冲上升时间小于或等于 2μs，且总的脉冲持续时间至少为 10μs**，则认为满足试验要求。未给出波形参数判 Fail；上升时间大于 2μs 或持续时间不足 10μs 判 Fail。
2. 核对信号源阻抗。说明：**信号源的标称阻抗应为 50Ω**；额定电压和持续时间**仅适用于开路状态**，与受试设备连接后峰值电压可能降低。未写明源阻抗判 Fail。
3. 核查试验装置的阻抗验证方法。说明：试验装置的源阻抗可用一个 **50Ω±10% 的负载电阻**试验验证，且**负载电阻上应产生规定电压一半 ±10% 的电压**。缺该验证方法判 Review。
4. 核查试验前波形验证。**断开受试设备，并按照要求验证瞬态波形**。检查单条目同样要求「明确验证电压尖峰瞬态波形的要求」。缺试验前波形验证判 Fail（波形未验证则整个试验结论不可信）。

## 08. 电压尖峰试验程序

- 规则编号：QTP-DO160G-17-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查施加对象、极性、次数、时间窗与工作模式覆盖。

### 审查内容

核查施加对象、极性、次数、时间窗与工作模式覆盖。

### 审查步骤

1. 核查设备工作状态与施加点。使受试设备**在其设计电压下工作**，向**每个主电源的输入端**施加正、负尖峰信号。未说明设备处于工作状态判 Fail；施加点不是主电源输入端判 Fail。
2. 核查多电源同时试验的要求。**对于由同一汇流条提供多种电源供电的情况，所有连接的电源线试验应同时进行**。存在同汇流条多路供电却逐路单独试验，判 Fail。
3. 核对施加次数与时间窗。**在 1min 内施加至少 50 次正极性瞬态信号，然后在 1min 内施加至少 50 次负极性瞬态信号**。次数不足 50 次、或未限定在 1min 内完成，判 Fail，并写明应为多少、实为多少。检查单条目同样要求「对电源线施加正负尖峰信号」。
4. 核查正负极性间隔。**施加正极性和负极性瞬态的间隔时间与试验目的无关，可由试验人员决定**。文档若对该间隔设置了严格限制并据此判不合格，属加严，判 Review。
5. 核查工作模式覆盖。**对受试设备的每个工作模式或功能重复上述试验**。检查单条目同样要求「更换受试设备工作模式重复试验」。仅测单一工作模式而未说明理由判 Fail。

## 09. 电压尖峰试验判据

- 规则编号：QTP-DO160G-17-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电压尖峰
- 规则说明：核查判据是否覆盖永久性损坏与性能降级两类影响，以及判定时机。

### 审查内容

核查判据是否覆盖永久性损坏与性能降级两类影响，以及判定时机。

### 审查步骤

1. 核查判据覆盖面。本试验关注的主要有害影响为 **a) 永久性损坏、元器件失效、绝缘击穿；b) 敏感度下降或设备性能改变**。判据未覆盖这两类影响判 Fail。
2. 核对判定时机。**施加电压尖峰后**，确定是否符合相应设备性能规范的要求。检查单条目同样表述为「施加电压尖峰后，设备性能是否符合相应规范要求」。在施加过程中即下最终结论而无过程监测依据，判 Review。
3. 核查过程监测的依据。**如果在试验期间要检查受试设备的性能，则要采用相关设备性能规范中规定的要求**。要求过程监测但未援引性能规范依据，判 Review。
4. 核查判据可判定性。仅写「符合 DO-160G 标准」而无具体判定项判 Review；完全未给判据判 Fail。
5. 核查偏离说明。检查单备注：若有偏离，应补充说明。存在与本章规定的偏离却无说明判 Fail。
