> 规则类型统一为 `test_item_chapter`，按关键词收敛到磁影响/磁效应章。

> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-15-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-15-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。承担该功能的设备已在本大纲的集中章节（如「6 试验设备描述」「12 设备功能检查」及本章明确引用的其他章节）中给出的，按被引用处的内容判定，视为已覆盖，不得因本章未重复罗列而判 Fail。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-15-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。设备参数在本大纲集中章节（如「6 试验设备描述」「12 设备功能检查」及本章明确引用的其他章节）中给出的，按被引用处的内容参与比较，不得因本章未重复列出而判 Fail。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-15-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-15-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 【建议项】核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求。大纲已按步骤 1、2 限定「等同或更优」的，即视为已覆盖该要求，判 Pass；无法逐项证明时仅在 suggestion 中建议补充能力对比说明，不判 Review、不计入 missing_items。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 磁影响试验 类别与判定距离

- 规则编号：QTP-DO160G-15-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：本章类别由「罗盘偏转 1° 时罗盘与设备的距离 D」决定，是试验结论而非前置条件，须与安装距离要求对应。

### 审查内容

核查类别定义与所声明类别、安装距离的对应关系。

### 审查步骤

1. 核查类别声明。标准按 D（观察到罗盘偏转 1° 时罗盘与设备的距离）划分五类。**下表两列是两个不同的量：判定类别只看「判据区间 D」这一列；右列是该类别对应的安装选位参考，不得拿右列数值去比对大纲给出的 D 区间。**

   | 类别 | 判据区间 D（据此判定类别） | 该类别适用的最小安装距离（参考） |
   |---|---|---|
   | Y | **D = 0.0m** | 0.0m~0.3m |
   | Z | **0 ＜ D ≤ 0.3m** | 大于 0.3m |
   | A | **0.3m ＜ D ≤ 1m** | 大于 1m |
   | B | **1m ＜ D ≤ 3m** | 大于 3m |
   | C | **D ＞ 3m** | 大于 3m |

   例：大纲声明 Z 类、判据写「0＜D≤0.3m」或「判定测量距离 D 在 0 米与 0.3 米之间」，与本表 Z 行判据区间一致，**判 Pass**。未声明类别判 Fail。
2. 核对类别与安装距离的对应。**先分清两个不同的量，不得互相比较**：`D` 是试验测得的「偏转 Dc 时罗盘轴心与 EUT 之间的最小距离」，是**试验结论**；「安装距离」是设备在飞机上距磁罗盘/磁通门的**布置要求**。
   - 大纲把判据写成 `0＜D≤0.3m`、`0＜D＜0.3m`、`D 在 0 与 0.3m 之间`并声明 Z 类的，与标准表 15 完全一致，**判 Pass**。同理 Y 类对应 `D=0.0m`、A 类 `0.3m＜D≤1m`、B 类 `1m＜D≤3m`、C 类 `D＞3m`。**不得因判据区间的上下限写法（含/不含端点、用「小于」或「不大于」）与规则用词不同而判不符。**
   - 【强制项】仅当大纲声明的类别与其自己给出的 D 区间**对应错行**（如声明 A 类却写 `D≤0.3m`）时判 Fail。
   - 【建议项】大纲未单独给出「安装距离」要求的，判 Pass 并在 suggestion 中建议与设备需求规范交叉确认；不得判 Fail、不得判 Review，更不得以「未给出安装距离」推翻已给出的类别与 D 判据。
3. 核查 C 类的距离记录要求。C 类**试验表格中应有偏转 1° 时的最小距离，并据此选择设备在飞机上的安装位置**。声明 C 类却未要求记录该最小距离判 Fail。

## 07. 磁场环境与偏转角修正

- 规则编号：QTP-DO160G-15-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查试验磁场强度要求、偏转角取值与环境场强超差时的修正方法。

### 审查内容

核查试验磁场强度要求、偏转角取值与环境场强超差时的修正方法。

### 审查步骤

1. 核对均匀磁场强度。受试设备的磁影响通过自由磁体在**水平强度为 14.4 A/m ±10%** 的均匀磁场中的等效偏转来确定。大纲可采用两种可接受方式：①使用试验室环境地磁场并测量其水平分量；②在试验区域直接建立并控制为 14.4 A/m ±10% 的均匀试验磁场。场强要求不符或未写明判 Fail。
2. 核对测量布置。试验时将受试设备放置在**通过磁体中心的东－西轴线**上，用**非补偿罗盘或等效磁传感器**测量偏转角。未说明东西轴线布置判 Fail；使用补偿罗盘判 Fail。
3. 核对判定偏转角。采用环境地磁场且其实测水平分量在 14.4 A/m±10% 内，或采用直接控制并已验证为 14.4 A/m±10% 的均匀试验磁场时，用于确定类别的**偏转角为 1°（Dc=1）**。
4. 核查超差时的修正。仅当采用**环境地磁场法**且其实测水平分量超出容差范围时，确定类别的偏转角才应按 **Dc = 1° × (14.4 A/m ÷ 环境场强的水平分量)** 修正。采用该方法却未说明测量与超差修正安排判 Fail。若大纲已明确直接建立并控制合格的 14.4 A/m±10% 均匀试验磁场，不得再以缺少地磁场修正公式判 Fail。
5. 核查 HCAFS 测量。采用环境地磁场法且 HCAFS（地球产生的环境磁场强度水平分量）未知时，**应首先测量 HCAFS 值**（例如用磁力计）；缺该前置测量判 Fail。若采用的是经测量验证、直接控制为 14.4 A/m±10% 的均匀试验磁场，HCAFS 测量不是额外必备项，不得据此报错。

## 08. 磁影响试验程序

- 规则编号：QTP-DO160G-15-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：核查电缆布置、工作模式与朝向选择、距离测量与均匀性验证。

### 审查内容

核查电缆布置、工作模式与朝向选择、距离测量与均匀性验证。

### 审查步骤

1. 核对电缆要求。EUT 通电并使用**与射频敏感度试验时相同或等同的电缆线**；试验时将 EUT 的**所有电缆和可延伸的电源电缆捆成一束**，并使该**电缆束沿罗盘的东-西轴线放置**。未说明电缆状态判 Fail；电缆与第20章不一致且无说明判 Review。
2. 核对工作模式选择。步骤4：启动 EUT，**选择能产生最大磁偏转角的 EUT 稳态工作模式**。未要求取最大偏转工作模式判 Fail（取非最坏模式会低估磁影响）。
3. 核对朝向选择。步骤5：保持电缆在东－西轴线不变，**选择产生最大磁偏转的 EUT 朝向**。未要求取最大偏转朝向判 Fail。
4. 核查移动对象与磁场均匀性。步骤6中必须明确“减小距离”是**移动 EUT 接近固定罗盘**，还是**移动罗盘接近固定 EUT**；只写“减小两者距离”而未说明移动对象时判 Review，不得自行假设。若移动 EUT 接近固定罗盘，不额外要求沿途均匀性 ±0.5°；若移动罗盘接近 EUT，则必须进行磁场均匀性试验——将 EUT 移出试验区域，罗盘沿计划路径直线移动至 EUT 位置过程中，偏转应不超过 **±0.5°**。采用移动罗盘方式却未安排均匀性试验判 Fail；均匀性判据不是 ±0.5° 判 Fail。
5. 核对距离测量与记录。步骤7：应测量并记录**磁体偏转 Dc 时其轴心与 EUT 部件之间的最小距离**。测量对象写成「设备中心」而非最小距离判 Fail；未要求记录判 Fail。
6. 核查类别判定依据。步骤8：应利用步骤7 测得的距离 D，类别区间选择设备类别。未说明由实测距离反推类别判 Review。

## 09. 磁影响试验判据

- 规则编号：QTP-DO160G-15-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：磁影响，磁效应
- 规则说明：对应本章试验目的与检查单「合格判据」条目。

### 审查内容

核查判据是否落到「实测距离满足所声明类别」与「不干扰临近设备」两点。

### 审查步骤

1. 核查距离判据。判据应明确：**实测的偏转 Dc 对应距离 D 落在所声明类别的区间内即合格**。仅写「符合 DO-160G 标准」而无距离判据判 Review；完全未给判据判 Fail。
2. 核查设备工作正常性。**判据齐备的标准是「距离判据 + 功能性能检测」两项**：大纲已给出 D 区间判据，且要求试验中/后按功能性能检查（如 QPAT、性能检测表）确认设备正常工作的，即判 Pass。
   - 「确保设备正常工作并对临近设备不产生干扰」是 DO-160G 15.1 对**试验目的**的表述，**不是独立的合格判据**。
   - 【建议项】大纲未单列「不干扰临近设备」判据的，判 Pass，仅可在 suggestion 中建议补充；**不得据此判 Fail 或 Review**。
   - 【强制项】仅当既无距离判据、又无任何功能性能检测要求时，才判 Fail。
3. 核查与安装位置的衔接。试验结论用于**确定设备与性能规范的符合性，或协助安装者选择设备在飞机上的适当安装位置**。【建议项】未说明试验结论如何用于安装距离要求的，判 Pass 并在 suggestion 中建议补充，不判 Review。【强制项】仅 C 类必须在试验表格中记录偏转 1° 时的最小距离（见本章 06 规则），缺失按该规则判定，本步骤不重复报告。
