# DO-160G 第11章 流体敏感性 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到流体敏感性章。

---

## 1. 流体敏感性 类别与试验流体规划

- 规则编号：QTP-DO160G-11-A
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：试验流体的种类与温度取自，是本章全部数值判据的前提。

### 审查内容

核查是否声明鉴定类别与试验流体清单，且流体规划覆盖设备实际所处的污染流体类别。

### 审查步骤

1. 核查鉴定类别声明。未声明本章鉴定试验类别判 Fail，并说明试验流体与温度无从核验。
2. 核查试验流体清单。检查单注：**试验流体的规划应保证设备所处液体环境中的污染流体类别被覆盖**。未列出具体流体名称判 Fail；列出但未说明其与设备实际使用环境的对应关系判 Review。
3. 核对流体温度。流体温度应保持在**规定值**。文档给出的流体温度与不一致判 Fail，并写明应为多少、实为多少；未给出温度判 Fail。
4. 核查试验方式的选择。提供**喷淋试验与浸渍试验**两种程序，由设备规范确定采用哪一种。既未说明采用哪种程序判 Fail。
5. 核查多流体试验的安排。设备要求用多种级别污染流体试验时**通常应分别进行**；流体基质相同的可同时进行（**油类流体试验后不应进行水性流体试验**）；**喷淋前流体不能预先混合**，使用顺序由设备规范规定；同时使用时全部暴露时间应与单一流体相同。将不同基质流体混合或同时使用判 Fail。

## 2. 喷淋试验程序

- 规则编号：QTP-DO160G-11-B
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查喷淋方式、润湿与干燥时长、循环数与末期通电要求。

### 审查内容

核查喷淋方式、润湿与干燥时长、循环数与末期通电要求。

### 审查步骤

1. 核对设备状态与试验环境。按设备规范进行机械和电气连接，**试验期间设备不要求工作**，试验在**实验室环境下**进行。写成全程工作判 Fail。
2. 核对喷淋方式与覆盖面。喷淋应**呈细雾状**，喷向设备的**每一个主要表面与密封接头**，覆盖所有可能暴露的表面。未覆盖密封接头判 Review；未说明喷淋形态判 Review。
3. 核对润湿与干燥时长。**保持表面湿润 8h，然后在 65℃ 条件下干燥 16h**。两个数值任一不符判 Fail，并写明应为多少、实为多少。
4. 核查润湿困难时的替代做法。若保持润湿有困难且规范要求做喷淋而非浸渍，**最多每隔 4h 充分喷淋一次**是可取的，并允许产品在标准环境温度下稳定。采用间歇喷淋但间隔超过 4h 判 Fail。
5. 核对循环数与末期通电。重复步骤 a **直到 3 个 24h 的循环周期结束**；**在第 3 个喷淋周期临近结束时应使设备至少工作 10min**；最后一个周期结束后将箱温降至试验标准大气温度（**避免温度冲击**）并使设备工作**直至稳定或不低于 30min**，再确定性能符合性。循环数不足 3 个、缺 10min 通电、缺 30min 工作，任一判 Fail。
6. 核对试验后检查。试验结束后应检查受试设备，**内部或外部的任何部件不应出现破坏现象**。缺该检查要求判 Review。

## 3. 浸渍试验程序

- 规则编号：QTP-DO160G-11-C
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查浸渍时长、覆盖要求、浸没状态下的通电、后续高温保持与恢复工作时长。

### 审查内容

核查浸渍时长、覆盖要求、浸没状态下的通电、后续高温保持与恢复工作时长。

### 审查步骤

1. 核对设备状态与试验环境。按设备规范进行机械和电气连接，**试验期间设备不工作**，试验在**环境温度下**进行，**不要预先混合任何溶液**。写成预混溶液判 Fail。
2. 核对浸渍时长与覆盖。把设备**浸入适当流体中至少 24h**，流体温度保持规定值，**流体要完全覆盖试件**。时长短于 24h 判 Fail；未要求完全覆盖判 Fail。
3. 核对浸没状态下的通电。**24h 结束时，设备至少工作 10min，此时设备仍全部浸在流体中**。缺此步、或时长不足、或在取出后才通电，均判 Fail。
4. 核对后续高温保持。取出试件放入试验箱，**在 65℃ 恒定温度下至少保持 160h**。温度或时长不符判 Fail，并写明应为多少、实为多少。
5. 核对恢复与最终工作时长。之后将试件**恢复常温并至少工作 2h**，工作 2h 后确定是否符合有关设备性能标准。时长不足或未写明判 Fail。
6. 核对试验后检查。应检查受试设备，**内部或外部任何部件不应出现破坏现象**。缺该要求判 Review。

## 4. 流体敏感性试验判据与材料试样

- 规则编号：QTP-DO160G-11-D
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查合格判据可判定性、材料试样替代的适用条件与安全注意事项。

### 审查内容

核查合格判据可判定性、材料试样替代的适用条件与安全注意事项。

### 审查步骤

1. 核查判据可判定性。仅写「符合设备性能标准」而无具体判定项判 Review；完全未给判据判 Fail。判据应覆盖**部件破坏检查**与**性能符合性**两方面。
2. 核查材料试样替代的说明。允许在特定条件下用材料试样代替整机进行试验。文档采用材料试样方式的，须说明所依据的条件与试样代表性；无说明判 Review。
3. 核查安全与注意事项。对试验流体的处置有注意事项要求。文档完全未涉及流体使用的安全防护判 Review（不作为技术符合性判 Fail 的依据）。
