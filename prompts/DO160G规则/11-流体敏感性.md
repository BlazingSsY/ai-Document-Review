# DO-160G 第11章 流体敏感性 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到流体敏感性章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-11-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有名称和型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号判 Fail，并逐台列出缺失项。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-11-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 将所需功能与设备清单逐项对应；缺少完成任一必需功能的设备，或设备清单与程序明显不一致，判 Fail，并说明缺少的设备功能。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-11-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 比对设备参数与本章试验范围、载荷量级和允许误差。量程或频率范围不能覆盖试验要求、精度不能满足试验允差，判 Fail，并列出“设备能力—本章要求”的差异。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 参数因图表不可读或解析缺失而无法确认时判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-11-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出校准周期、有效期或可核验的校准状态；完全缺失判 Fail。
2. 核查是否明确要求试验实施时设备处于校准有效期内；只列周期但未约束试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-11-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 宜要求在试验记录中写明替代设备、替代理由和能力对比；存在替代条款但无记录要求判 Review。

## 06. 流体敏感性 类别与试验流体规划

- 规则编号：QTP-DO160G-11-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：试验流体的种类与温度取自，是本章全部数值判据的前提。

### 审查内容

核查是否声明鉴定类别与试验流体清单，且流体规划覆盖设备实际所处的污染流体类别。

### 审查步骤

1. 核查鉴定类别声明。未声明本章鉴定试验类别判 Fail，并说明试验流体与温度无从核验。
2. 核查试验流体清单。检查单注：**试验流体的规划应保证设备所处液体环境中的污染流体类别被覆盖**。未列出具体流体名称判 Fail；列出但未说明其与设备实际使用环境的对应关系判 Review。
3. 核对流体温度。流体温度应保持在**规定值**。文档给出的流体温度与不一致判 Fail，并写明应为多少、实为多少；未给出温度判 Fail。
4. 核查试验方式的选择。提供**喷淋试验与浸渍试验**两种程序，由设备规范确定采用哪一种。既未说明采用哪种程序判 Fail。
5. 核查多流体试验的安排。设备要求用多种级别污染流体试验时**通常应分别进行**；流体基质相同的可同时进行（**油类流体试验后不应进行水性流体试验**）；**喷淋前流体不能预先混合**，使用顺序由设备规范规定；同时使用时全部暴露时间应与单一流体相同。将不同基质流体混合或同时使用判 Fail。

## 07. 喷淋试验程序

- 规则编号：QTP-DO160G-11-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查喷淋方式、润湿与干燥时长、循环数与末期通电要求。

### 审查内容

核查喷淋方式、润湿与干燥时长、循环数与末期通电要求。

### 审查步骤

1. 核对设备状态与试验环境。按设备规范进行机械和电气连接，**试验期间设备不要求工作**，试验在**实验室环境下**进行。写成全程工作判 Fail。
2. 核对喷淋方式与覆盖面。喷淋应**呈细雾状**，喷向设备的**每一个主要表面与密封接头**，覆盖所有可能暴露的表面。未覆盖密封接头判 Review；未说明喷淋形态判 Review。
3. 核对润湿与干燥时长。**保持表面湿润 8h，然后在 65℃ 条件下干燥 16h**。两个数值任一不符判 Fail，并写明应为多少、实为多少。
4. 核查润湿困难时的替代做法。若保持润湿有困难且规范要求做喷淋而非浸渍，**最多每隔 4h 充分喷淋一次**是可取的，并允许产品在标准环境温度下稳定。采用间歇喷淋但间隔超过 4h 判 Fail。
5. 核对循环数与末期通电。重复步骤 a **直到 3 个 24h 的循环周期结束**；**在第 3 个喷淋周期临近结束时应使设备至少工作 10min**；最后一个周期结束后将箱温降至试验标准大气温度（**避免温度冲击**）并使设备工作**直至稳定或不低于 30min**，再确定性能符合性。循环数不足 3 个、缺 10min 通电、缺 30min 工作，任一判 Fail。
6. 核对试验后检查。试验结束后应检查受试设备，**内部或外部的任何部件不应出现破坏现象**。缺该检查要求判 Review。

## 08. 浸渍试验程序

- 规则编号：QTP-DO160G-11-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查浸渍时长、覆盖要求、浸没状态下的通电、后续高温保持与恢复工作时长。

### 审查内容

核查浸渍时长、覆盖要求、浸没状态下的通电、后续高温保持与恢复工作时长。

### 审查步骤

1. 核对设备状态与试验环境。按设备规范进行机械和电气连接，**试验期间设备不工作**，试验在**环境温度下**进行，**不要预先混合任何溶液**。写成预混溶液判 Fail。
2. 核对浸渍时长与覆盖。把设备**浸入适当流体中至少 24h**，流体温度保持规定值，**流体要完全覆盖试件**。时长短于 24h 判 Fail；未要求完全覆盖判 Fail。
3. 核对浸没状态下的通电。**24h 结束时，设备至少工作 10min，此时设备仍全部浸在流体中**。缺此步、或时长不足、或在取出后才通电，均判 Fail。
4. 核对后续高温保持。取出试件放入试验箱，**在 65℃ 恒定温度下至少保持 160h**。温度或时长不符判 Fail，并写明应为多少、实为多少。
5. 核对恢复与最终工作时长。之后将试件**恢复常温并至少工作 2h**，工作 2h 后确定是否符合有关设备性能标准。时长不足或未写明判 Fail。
6. 核对试验后检查。应检查受试设备，**内部或外部任何部件不应出现破坏现象**。缺该要求判 Review。

## 09. 流体敏感性试验判据与材料试样

- 规则编号：QTP-DO160G-11-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：流体敏感性
- 规则说明：核查合格判据可判定性、材料试样替代的适用条件与安全注意事项。

### 审查内容

核查合格判据可判定性、材料试样替代的适用条件与安全注意事项。

### 审查步骤

1. 核查判据可判定性。仅写「符合设备性能标准」而无具体判定项判 Review；完全未给判据判 Fail。判据应覆盖**部件破坏检查**与**性能符合性**两方面。
2. 核查材料试样替代的说明。允许在特定条件下用材料试样代替整机进行试验。文档采用材料试样方式的，须说明所依据的条件与试样代表性；无说明判 Review。
3. 核查安全与注意事项。对试验流体的处置有注意事项要求。文档完全未涉及流体使用的安全防护判 Review（不作为技术符合性判 Fail 的依据）。
