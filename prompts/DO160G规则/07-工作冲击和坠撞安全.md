# DO-160G 第7章 工作冲击和坠撞安全 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到冲击/坠撞安全章。

---

## 1. 冲击试验前通用准备

- 规则编号：QTP-DO160G-07-A
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：工作冲击和坠撞安全,坠撞安全,加速度
- 规则说明：核查安装信息、测点布置、测量精度与脉冲持续时长选择依据是否齐备。

### 审查内容

核查安装信息、测点布置、测量精度与脉冲持续时长选择依据是否齐备。

### 审查步骤

1. 核查受试设备安装信息。应用**刚性试验夹具**和**实际安装所使用的安装方法**将设备固定在冲击台面上，安装宜包括正常安装所用的非结构连接件。文档须以图示或文字给出安装信息；缺失判 Fail。对外部装有减振器/缓冲器的设备，应装上减振器/缓冲器进行试验，未说明判 Review。
2. 核查安装方式的代表性。安装方式应可代表机上安装状态。文档未说明与机上安装的一致性判 Review。
3. 核查加速度测点布置。用于测量或控制输入冲击脉冲的加速度计，应安装在**尽可能靠近设备固定点**的位置。缺测点布置方案（图示或文字）判 Fail；有方案但未体现"靠近固定点/设备与夹具连接点"原则判 Review。
4. 核查测量系统精度。测量加速度的试验系统精度应在标准读数的 **±10%** 范围内。未写明精度要求判 Fail；写明但宽于 ±10% 判 Fail。
5. 核查脉冲持续时长的选择依据。检查单要求给出通过振动试验扫频程序或其他方式获取的**设备最低共振频率**，并据此选择正确的脉冲持续时长（标准冲击 11ms / 低频冲击 20ms）。未给出依据判 Review；选了低频 20ms 却无最低共振频率支撑判 Fail。

## 2. 工作冲击试验

- 规则编号：QTP-DO160G-07-B
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：工作冲击和坠撞安全,坠撞安全
- 规则说明：核查工作冲击的量级、波形、脉冲时长、冲击次数与设备工作状态。

### 审查内容

核查工作冲击的量级、波形、脉冲时长、冲击次数与设备工作状态。

### 审查步骤

1. 核对冲击量级与波形。冲击波形采用**后峰锯齿波**，**冲击加速度峰值 6g**。可使用**等效冲击响应谱**取代后峰锯齿波形。量级或波形不符判 Fail，并写明应为多少、实为多少。
2. 核对脉冲持续时间。**标准冲击试验标称脉冲持续时间 11ms；低频冲击试验 20ms**。数值不符判 Fail；未写明判 Fail。
3. 核对冲击次数与方向。在设备处于工作状态且温度稳定后，**对每个方向进行 3 次冲击**，方向为常规跌落冲击机的六个取向（正常直立、悬挂倒置、第一主正交轴±90度、第二主正交轴±90度）。替代程序：按正常工作方向安装，**在三个正交轴的两个方向上各施加 3 次冲击**。文档采用任一程序均可，但须与所选程序完全一致；次数或方向数不足判 Fail。
4. 核查设备工作状态与性能确认。设备**处于工作状态**且温度稳定后施加冲击；冲击完成后确定是否符合有关设备性能标准。引言：若要求在施加冲击脉冲**期间**监测设备，必须在相关设备规范中提出监测要求。未说明工作状态判 Fail；要求过程监测但未在规范中提出依据判 Review。

## 3. 坠撞安全冲击试验

- 规则编号：QTP-DO160G-07-C
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：工作冲击和坠撞安全,坠撞安全
- 规则说明：核查坠撞安全冲击的量级、次数、模拟负载使用与合格判据。

### 审查内容

核查坠撞安全冲击的量级、次数、模拟负载使用与合格判据。

### 审查步骤

1. 核查程序完整性。**如果要进行坠撞安全试验，冲击试验程序和持续载荷试验程序都应进行**。只做其中之一判 Fail。
2. 核对冲击量级与次数。对 列出的**六个设备方向的每一方向各施加 1 次 20g 冲击**，冲击波形与、规定相同。替代程序：按正常工作方向安装，在三个正交轴的两个方向上施加冲击。量级不是 20g、或次数不足每方向 1 次，判 Fail。
3. 核查等效质量（模拟负载）的使用。可用等效质量代替正常安装在机箱内或机架上的电气-机械部件；等效质量应**接近被替代部件的质量**，放置位置应使**设备重心基本不变**，且**不应显著增加机箱或安装连接装置的强度**。文档使用模拟负载但未说明上述三项约束，判 Review；明显违反（如用加强件替代）判 Fail。
4. 核对合格判据。六次冲击后**允许有弯曲和变形，但安装连接件不应出现破坏，设备或模拟负载仍应保持在原位**。判据写成「不允许任何变形」属加严、写成「允许脱落」属放松，均判 Fail；未给判据判 Fail。

## 4. 坠撞安全持续载荷试验

- 规则编号：QTP-DO160G-07-D
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：工作冲击和坠撞安全,坠撞安全,加速度,持续加速度
- 规则说明：核查持续载荷的量级、方向、保载时长与加载方式。

### 审查内容

核查持续载荷的量级、方向、保载时长与加载方式。

### 审查步骤

0. 先判断本章是否承载本项内容。本项对应的试验在不同大纲里有两种编排：一种与工作冲击、坠撞冲击合写在同一章，另一种单独成章（常命名为「加速度试验」或「坠撞安全持续加速度试验」）。**若当前章节未包含持续加速度/持续载荷内容，且大纲在其他章节单独编排了该试验，本项在本章判为不适用，不计入缺失**；只有当全文都找不到该试验时才判 Fail。
1. 核对保载时长。对**每个载荷方向至少施加 3s** 适当的试验载荷。短于 3s 或未写明判 Fail。
2. 核对载荷量级。按飞机类型与试验类型取值（单位 g，方向依次为 上/下/前/后/侧向）：**直升机** F=16.0/NA/8.0，R=全部 20.0；**固定翼运输机** F=3.0/9.0/1.5/4.0，R=全部 9.0；**固定翼非运输机** F=3.0/NA/18.0/NA/4.5，R=全部 18.0；**所有固定翼飞机** F=3.0/18.0/1.5/4.5，R=全部 18.0；**直升机和所有固定翼飞机** F=18.0/1.5/8.0，R=全部 20.0。其中 **F 为安装方向已知且固定的设备，R 为安装方向未知或任意的设备**，侧向包含左右两个方向。量级低于本机型/试验类型的规定值判 Fail，并写明应为多少、实为多少。
3. 核查方向选取。设备相对飞机轴向方位已知时，据此确定载荷量值与方向；**方位未知或不固定时，需按规定的设备三个正交轴向的每一方向随机选取方向**（即取 R 行量级）。方位未知却按 F 行取值判 Fail。
4. 核查载荷方向的物理含义。坠撞安全载荷代表**惯性载荷**，载荷方向与加速度 g 方向相同；用静态力试验时载荷方向宜与 g 方向一致；**用离心机时载荷方向与加速度方向相反**，设备朝向必须确保载荷处于正确方向。文档采用离心机但未说明设备朝向如何保证载荷方向正确，判 Review；方向描述明显颠倒判 Fail。
5. 核对合格判据。完成六个方向加载后，**允许出现弯曲与变形，但安装连接件不应出现破坏，设备或模拟负载应保持在原位**。判据不符判 Fail。

## 5. 冲击与坠撞安全试验判据

- 规则编号：QTP-DO160G-07-E
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：工作冲击和坠撞安全,坠撞安全,加速度
- 规则说明：对应检查单「试验判据」条目与本章整体要求。

### 审查内容

核查试验量级与测量精度是否满足标准要求，判据是否覆盖功能与结构完整性。

### 审查步骤

1. 核查量级与精度的符合性说明。检查单要求试验量级和测试精度满足 DO-160G 第七章要求：工作冲击 6g/11ms（低频 20ms）、坠撞冲击 20g、持续载荷按、测量系统精度 ±10%。任一项与标准不符判 Fail。
2. 核查功能完整性判据。检查单注：应提供检查设备功能和结构完整性的方法，**电子设备应确保试验过程中设备功能正常，应明确具体检测方法**。仅写「功能正常」而无检测方法判 Review；未提功能判据判 Fail。
3. 核查结构完整性判据。须体现「允许弯曲变形、安装连接件不破坏、设备保持原位」原则。缺结构完整性判据判 Fail。
4. 若文档包含鸟撞冲击等本章之外的试验项目，核查其是否给出所依据的企业标准或型号规范出处。标准不含鸟撞冲击，无出处判 Review，不按 DO-160G 判其量级。
