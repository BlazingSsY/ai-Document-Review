# DO-160G 第5章 温度变化 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到温度变化章。

---

## 1. 温度变化试验 类别与速率声明

- 规则编号：QTP-DO160G-05-A
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：温度变化速率由类别决定，类别未声明则速率无从核验。注意本章类别（A/B/C/S1/S2）与第4章温度－高度的设备类别是两套体系，不可混用。

### 审查内容

核查是否声明温度变化速率类别，且与设备安装区域相符、全章一致。

### 审查步骤

1. 查找温度变化类别代号。标准 规定五类：**A类**（飞机外部或内部设备）、**B类**（内部温度不控制或部分控制区）、**C类**（内部温度控制区）、**S1类**（温度变化速率已知且大于10℃/min）、**S2类**（未知是否大于10℃/min）。未声明类别判 Fail，并说明速率判据无从核验。
2. 核对类别与安装区域是否自洽。满足 B 类的设备也可认为满足 C 类；注3)：S1/S2 用于温度冲击场景，速率已知用 S1、否则用 S2。明显矛盾判 Fail；未说明安装区域判 Review。
3. 核查是否混淆了两套类别体系。本章类别是 A/B/C/S1/S2，温度－高度试验的设备类别是 A1~F3。若本章用 A1、D2 这类第4章代号描述温度变化速率类别，判 Fail 并指出应使用 的类别划分。

## 2. 温度变化速率与温度极值

- 规则编号：QTP-DO160G-05-B
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查温度变化速率、工作高温、工作低温三个数值是否与所声明的类别规定一致。

### 审查内容

核查温度变化速率、工作高温、工作低温三个数值是否与所声明的类别规定一致。

### 审查步骤

1. 核对温度变化速率。**A类最小 10℃/min；B类最小 5℃/min；C类最小 2℃/min；S1类大于 10℃/min 且须在合格鉴定表中注明具体值；S2类速率未知**。文档给出的速率低于本类别的最小值判 Fail，并写明应为多少、实为多少；S1 类未注明具体速率值判 Fail。
2. 核对工作高温与工作低温。二者取自高温工作温度与低温工作温度行，依设备（第4章）类别确定：低温工作温度 A1~A4=-15；B1=-20，B2/B3=-45，B4=注(4)；C1=-20，C2/C3=-55，C4=注(4)；D1=-20，D2/D3=-55；E1/E2=-55；F1=-20，F2/F3=-55。高温工作温度 A1=+55，A2/A3=+70，A4=注(3)；B1=+55，B2=+70，B3=注(3)，B4=注(4)；C1=+55，C2=+70，C3=注(3)，C4=注(4)；D1=+55，D2=+70，D3=注(3)；E1/E2=注(3)；F1=+55，F2=+70，F3=注(3)。与规定值不一致判 Fail 并写明应为多少、实为多少。
3. 核对循环数量。**至少应完成两个循环**。少于 2 个循环判 Fail；未写明循环数判 Fail。若文档说明因单循环内无法完成全部性能符合性确认而增加循环次数，属 允许情形，通过。

## 3. A/B/C 类温度变化试验程序

- 规则编号：QTP-DO160G-05-C
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查试验程序是否覆盖标准规定的关键动作与驻留时间。

### 审查内容

核查试验程序是否覆盖标准规定的关键动作与驻留时间。

### 审查步骤

1. 核查低温段起始。非组合试验时，在环境温度下使设备工作，速率将箱温降至低温工作温度，并使处于工作状态的设备温度稳定。缺「按规定速率降温」或缺「工作状态下稳定」判 Fail。
2. 核查升温段的性能确认。按规定速率将箱温升至高温工作温度，**在此温度变化期间**确定是否符合设备性能标准。仅在温度到达后测试、而未要求变化过程中确认，判 Fail。
3. 核查高温驻留。设备在高温工作温度下达到温度稳定后，**保持不工作状态至少 2min**。缺此步或时间短于 2min 判 Fail。
4. 核查降温段与低温驻留。启动设备按规定速率降至低温工作温度，变化期间确认性能；温度稳定后**使设备至少工作 1h，而后断电 30min**，在箱温保持低温工作温度下重新启动设备。三个数值（1h 工作、30min 断电、断电期间维持低温）缺任一或不符判 Fail。
5. 核查回温与最终确认。按规定速率升至试验室环境温度，箱温与设备达到温度稳定后确定性能符合性。缺此步判 Review。
6. 核查凝露控制。注与 末段：试验箱应能将湿度控制在使冷凝降到最小或不发生的范围；温度升高可能产生凝露危险时应控制箱内空气湿度。完全未提凝露控制判 Review。

## 4. S1/S2 类温度冲击程序

- 规则编号：QTP-DO160G-05-D
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查 S1/S2 类设备是否按温度冲击程序而非 A/B/C 类程序编写。

### 审查内容

核查 S1/S2 类设备是否按温度冲击程序而非 A/B/C 类程序编写。

### 审查步骤

1. 核查适用性。仅 S1、S2 类需按温度冲击程序试验；A/B/C 类。若设备声明为 S1/S2 却套用 的 A/B/C 程序，判 Fail；若为 A/B/C 类，本规则不适用，判「不适用」。
2. 若为 S1 类，核查是否注明了已知的温度变化速率具体值（5.2 S1 类要求「应在合格鉴定表中注明温度变化速率具体值」）。未注明判 Fail。
3. 核查温度冲击的两端温度是否取高温工作温度与低温工作温度，且转换过程符合 的规定。温度取值与不符判 Fail。

## 5. 温度变化试验判据

- 规则编号：QTP-DO160G-05-E
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查是否给出可判定的合格判据，并覆盖温度变化过程中的性能确认。

### 审查内容

核查是否给出可判定的合格判据，并覆盖温度变化过程中的性能确认。

### 审查步骤

1. 核查判据是否可判定。仅写「符合设备性能标准」而无具体判定项与门限，判 Review；完全未给判据判 Fail。
2. 核查是否覆盖「温度变化过程中」的性能确认，而不只是稳定后的确认。5.3.1 c 与 e 均要求在温度变化期间确定符合性。只在温度稳定点测试判 Fail。
3. 核查是否说明了循环内测试的安排。若一次循环的每一温度变化段都能完成符合性确认，则仅需在第二个循环期间测试；若变化段时间不足以完成确认，应增加循环次数。文档对测试安排完全未说明判 Review。
