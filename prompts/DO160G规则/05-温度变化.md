## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-05-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-05-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。承担该功能的设备已在本大纲的集中章节（如「6 试验设备描述」「12 设备功能检查」及本章明确引用的其他章节）中给出的，按被引用处的内容判定，视为已覆盖，不得因本章未重复罗列而判 Fail。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-05-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。设备参数在本大纲集中章节（如「6 试验设备描述」「12 设备功能检查」及本章明确引用的其他章节）中给出的，按被引用处的内容参与比较，不得因本章未重复列出而判 Fail。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-05-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-05-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 【建议项】核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求。大纲已按步骤 1、2 限定「等同或更优」的，即视为已覆盖该要求，判 Pass；无法逐项证明时仅在 suggestion 中建议补充能力对比说明，不判 Review、不计入 missing_items。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 温度变化试验 类别与速率声明

- 规则编号：QTP-DO160G-05-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：温度变化速率由类别决定，类别未声明则速率无从核验。注意本章类别（A/B/C/S1/S2）与第4章温度－高度的设备类别是两套体系，不可混用。

### 审查内容

核查是否声明温度变化速率类别，且与设备安装区域相符、全章一致。

### 审查步骤

1. 查找温度变化类别代号。标准 规定五类：**A类**（飞机外部或内部设备）、**B类**（内部温度不控制或部分控制区）、**C类**（内部温度控制区）、**S1类**（温度变化速率已知且大于10℃/min）、**S2类**（未知是否大于10℃/min）。未声明类别判 Fail，并说明速率判据无从核验。
2. 核对类别与安装区域是否自洽。满足 B 类的设备也可认为满足 C 类；注3)：S1/S2 用于温度冲击场景，速率已知用 S1、否则用 S2。明显矛盾判 Fail。大纲已写出安装区域（如「装于飞机设备舱前电子舱」）即视为已说明，判 Pass，不得因未与设备需求规范逐项比对而判 Fail 或 Review；完全未提及安装区域时才判 Review。【建议项】与设备需求规范、鉴定计划的交叉确认属推荐做法，仅在 suggestion 中提出。
3. 核查是否混淆了两套类别体系。本章类别是 A/B/C/S1/S2，温度－高度试验的设备类别是 A1~F3。若本章用 A1、D2 这类第4章代号描述温度变化速率类别，判 Fail 并指出应使用 的类别划分。

## 07. 温度变化速率与温度极值

- 规则编号：QTP-DO160G-05-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查温度变化速率、工作高温、工作低温三个数值是否与所声明的类别规定一致。

### 审查内容

核查温度变化速率、工作高温、工作低温三个数值是否与所声明的类别规定一致。

### 审查步骤

1. 核对温度变化速率。**A类最小 10℃/min；B类最小 5℃/min；C类最小 2℃/min；S1类大于 10℃/min 且须在合格鉴定表中注明具体值；S2类速率未知**。文档给出的速率低于本类别的最小值判 Fail，并写明应为多少、实为多少；S1 类未注明具体速率值判 Fail。
2. 核对工作高温与工作低温。二者取自高温工作温度与低温工作温度行，依设备（第4章）类别确定：低温工作温度 A1~A4=-15；B1=-20，B2/B3=-45，B4=注(4)；C1=-20，C2/C3=-55，C4=注(4)；D1=-20，D2/D3=-55；E1/E2=-55；F1=-20，F2/F3=-55。高温工作温度 A1=+55，A2/A3=+70，A4=注(3)；B1=+55，B2=+70，B3=注(3)，B4=注(4)；C1=+55，C2=+70，C3=注(3)，C4=注(4)；D1=+55，D2=+70，D3=注(3)；E1/E2=注(3)；F1=+55，F2=+70，F3=注(3)。与规定值不一致判 Fail 并写明应为多少、实为多少。
3. 核对循环数量。**至少应完成两个循环**。少于 2 个循环判 Fail；未写明循环数判 Fail。若文档说明因单循环内无法完成全部性能符合性确认而增加循环次数，属 允许情形，通过。

## 08. A/B/C 类温度变化试验程序

- 规则编号：QTP-DO160G-05-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查试验程序是否覆盖标准规定的关键动作与驻留时间。

### 审查内容

核查试验程序是否覆盖标准规定的关键动作与驻留时间。

### 审查步骤

1. 核查低温段起始。非组合试验时，在环境温度下使设备工作，速率将箱温降至低温工作温度，并使处于工作状态的设备温度稳定。缺「按规定速率降温」或缺「工作状态下稳定」判 Fail。
2. 核查升温段的性能确认。按规定速率将箱温升至高温工作温度，**在此温度变化期间**确定是否符合设备性能标准。仅在温度到达后测试、而未要求变化过程中确认，判 Fail。
3. 核查高温驻留。设备在高温工作温度下达到温度稳定后，**保持不工作状态至少 2min**。缺此步或时间短于 2min 判 Fail。
4. 核查降温段与低温驻留。启动设备按规定速率降至低温工作温度，变化期间确认性能；温度稳定后**使设备至少工作 1h，而后断电 30min**，在箱温保持低温工作温度下重新启动设备。三个数值（1h 工作、30min 断电、断电期间维持低温）缺任一或不符判 Fail。
5. 核查回温与最终确认。按规定速率升至试验室环境温度，箱温与设备达到温度稳定后确定性能符合性。缺此步判 Review。
6. 核查凝露控制。注与 末段：试验箱应能将湿度控制在使冷凝降到最小或不发生的范围；温度升高可能产生凝露危险时应控制箱内空气湿度。完全未提凝露控制判 Review。

## 09. S1/S2 类温度冲击程序

- 规则编号：QTP-DO160G-05-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查 S1/S2 类设备是否按温度冲击程序而非 A/B/C 类程序编写。

### 审查内容

核查 S1/S2 类设备是否按温度冲击程序而非 A/B/C 类程序编写。

### 审查步骤

1. 核查适用性。DO-160G 5.1：**A、B、C 类按 5.3.1 温度变化程序试验；只有 S1、S2 类才按 5.3.2/5.3.3 温度冲击程序试验**。
   - 原文已声明设备为 **A/B/C 类**（含 B 类）的，本规则**判 Pass**，reason 写明「温度冲击程序仅适用于 S1、S2 类，本设备为 X 类，不适用」。**严禁输出「不适用」「N/A」作为状态，也不得判 Review**——本系统只有 Pass/Fail/Review 三态，不适用一律落为 Pass。
   - 【强制项】设备声明为 S1/S2 却套用 A/B/C 的温度变化程序，判 Fail。
   - 仅当全文未声明温度变化类别、无法判断适用性时，才判 Review。
2. 若为 S1 类，核查是否注明了已知的温度变化速率具体值（5.2 S1 类要求「应在合格鉴定表中注明温度变化速率具体值」）。未注明判 Fail。
3. 核查温度冲击的两端温度是否取高温工作温度与低温工作温度，且转换过程符合 的规定。温度取值与不符判 Fail。

## 10. 温度变化试验判据

- 规则编号：QTP-DO160G-05-10
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：温度变化
- 规则说明：核查是否给出可判定的合格判据，并覆盖温度变化过程中的性能确认。

### 审查内容

核查是否给出可判定的合格判据，并覆盖温度变化过程中的性能确认。

### 审查步骤

1. 核查判据是否可判定。仅写「符合设备性能标准」而无具体判定项与门限，判 Review；完全未给判据判 Fail。
2. 核查是否覆盖「温度变化过程中」的性能确认，而不只是稳定后的确认。5.3.1 c 与 e 均要求在温度变化期间确定符合性。只在温度稳定点测试判 Fail。
3. 核查是否说明了循环内测试的安排。若一次循环的每一温度变化段都能完成符合性确认，则仅需在第二个循环期间测试；若变化段时间不足以完成确认，应增加循环次数。文档对测试安排完全未说明判 Review。
