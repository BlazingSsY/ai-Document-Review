# 试验项目一览表与试验章节一致性审查规则（文档级）

> 全部规则类型为**文档级**，在各章节审完后单独执行一次，证据包内含完整章节目录与各章原文摘录。
>
> 本文件只做一件事：**把试验概述中的试验项目一览表逐行拆开，与正文各试验章节逐一核对**。
> 一览表是全篇的策划基准，它与正文脱节意味着「计划做的」和「实际写的」不是一回事。
>
> **共同的输出要求（每条规则都适用）**：一览表通常有 20~30 行，涉及同样数量的章节。为在
> 「查全」与「输出长度可控」之间取平衡，按下列**三层**组织结论：
>
> 1. **不一致行必须全部展开**，逐条写明差异内容，一条都不能省略、不能合并；
> 2. **一致行只列序号**，形如「一致：序号 1、2、5、7~12、15」——不展开详情。若一致行不超过
>    10 行，可以展开；超过 10 行必须用序号列表压缩；
> 3. **统计数字必须完整给出**，见各规则最后一步的要求。
>
> **统计数字是这条规则是否真的查全的唯一凭据**：各项数字之和必须等于一览表总行数，对不上
> 就说明有行没核对。只给「基本一致」「大部分对应」这类总体结论、或统计数字缺失／对不上，
> 一律视为**未完成审查，直接判 Fail**。凡有任何一行不一致，整条规则判 Fail。
>
> 注：各规则所需的 DO-160G 参照数据分别写在对应规则的审查步骤内，不放在本前言——规则被
> 逐条注入模型，只有写进规则正文的内容才会随规则一起送达。

## 01. 试验项目一览表的存在性与结构完整性

- 规则编号：QTP-LIST-01
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,试验概述
- 规则说明：一览表是后续全部逐行核对的基准，其本身必须存在且信息列齐备。

### 审查内容

核查试验概述章中试验项目一览表是否存在，以及表中是否具备逐行核对所必需的信息列。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 定位一览表。在试验概述章中查找**试验项目一览表**（表名通常为「试验项目一览表」「试验项目表」或类似）。找不到该表判 Fail —— 无基准则全篇试验项目无从核对，并说明后续各项一致性检查均无法执行。
2. 核查必需信息列。表中应至少具备以下信息：**试验项目名称**、**试验类别**、**是否开展（或等效的执行状态标识）**。缺少「试验项目名称」列判 Fail；缺少「试验类别」列判 Fail 并说明各章类别将失去比对基准；缺少「是否开展」列判 Review。
3. 核查引用标准条款列。表中宜给出每个项目对应的引用标准条款（如「第4章 温度和高度 第4.5.1条」）。缺失判 Review —— 它是判断项目归属哪一章的辅助依据。
4. 核查章节对应列。若大纲另有「试验项目计划时间安排表」或类似表格给出**对应试验大纲章节号**，应一并作为核对依据。两表所列项目不一致（项目数、名称、顺序），判 Fail 并列出差异行。
5. 核查试件分配列。若表中有备注列标注试件分配（如「试件1/试件2」），核查其取值在全表中是否规范一致。出现无法识别的试件标识，判 Review。
6. 清点并输出总行数。输出一览表的**总行数与项目总数**（注意同一章可能拆成多行子项），作为后续各条规则逐行核对的基数。

### 原子检查项

- 检查项编号：QTP-LIST-01-C001
  检查项：试验概述章中是否存在试验项目一览表
  通过标准：能定位到「试验项目一览表」「试验项目表」或等效表格

- 检查项编号：QTP-LIST-01-C002
  检查项：一览表是否具备试验项目名称、试验类别、是否开展三列
  通过标准：三列齐备；缺项目名称列或试验类别列判 Fail，缺是否开展列判 Review

- 检查项编号：QTP-LIST-01-C003
  检查项：一览表是否给出每个项目对应的引用标准条款
  通过标准：各行均给出引用条款；缺失判 Review

- 检查项编号：QTP-LIST-01-C004
  检查项：若另有计划时间安排表，其所列项目是否与一览表一致
  通过标准：项目数、名称、顺序三者一致；不一致判 Fail 并列出差异行

- 检查项编号：QTP-LIST-01-C005
  检查项：备注列的试件分配标识是否全表规范一致
  通过标准：取值可识别且全表一致；出现无法识别的试件标识判 Review

- 检查项编号：QTP-LIST-01-C006
  检查项：是否清点并输出一览表的总行数与项目总数
  通过标准：给出总行数与项目总数，作为后续逐行核对的基数

## 02. 试验项目名称与试验章节的逐行对应

- 规则编号：QTP-LIST-02
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,试验项目
- 规则说明：逐行核对一览表每个项目是否都能在正文找到承载它的试验章节，并反向核查正文章节是否都在表中。

### 审查内容

将一览表逐行拆开，为每一行在正文中定位承载该试验的章节，并做正反双向核对。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 逐行定位承载章节。**对一览表的每一行**，在全文章节目录中找出承载该试验的章节。按分层要求输出：**未对应的行逐条展开**，写明「序号N 项目名称 → 未找到对应章节」；**已对应的行只列序号**（如「已对应：序号 1、2、5、7~12」），一致行不超过 10 行时可展开。
2. 判定名称对应关系时，以下为 DO-160G 全部环境试验的**规范名称与常见别名**，两侧名称属同一行即视为对应：

   | 标准章 | 规范名称 | 常见别名 |
   |---|---|---|
   | 第4章 | 温度－高度 | 温度和高度、温度高度 |
   | 第5章 | 温度变化 | 温度变化试验 |
   | 第6章 | 湿热 | 湿热试验 |
   | 第7章 | 工作冲击和坠撞安全 | 冲击及坠撞安全、冲击试验 |
   | 第8章 | 振动 | 振动试验 |
   | 第9章 | 爆炸大气 | 防爆性、爆炸性大气、防爆试验 |
   | 第10章 | 防水性 | 防水、防水试验 |
   | 第11章 | 流体敏感性 | 流体敏感性试验、耐流体 |
   | 第12章 | 砂尘 | 砂尘试验、吹砂吹尘 |
   | 第13章 | 霉菌 | 霉菌试验、防霉 |
   | 第14章 | 盐雾 | 盐雾试验 |
   | 第15章 | 磁影响 | 磁效应、磁效应试验 |
   | 第16章 | 电源输入 | 电源输入试验、供电特性 |
   | 第17章 | 电压尖峰 | 电压尖峰试验、尖峰信号 |
   | 第18章 | 音频传导敏感度－电源输入 | 电源线音频传导敏感度、音频传导敏感性 |
   | 第19章 | 感应信号敏感度 | 感应信号敏感性 |
   | 第20章 | 射频敏感度（辐射和传导） | 射频敏感性、辐射敏感度、传导敏感度 |
   | 第21章 | 射频能量发射 | 射频发射、辐射发射 |
   | 第22章 | 雷电感应瞬态敏感度 | 闪电感应瞬态敏感性、雷电感应瞬变敏感性 |
   | 第23章 | 雷电直接效应 | 闪电直接效应 |
   | 第24章 | 结冰 | 结冰试验、积冰 |
   | 第25章 | 静电放电 | ESD、静电放电试验 |
   | 第26章 | 防火，可燃性 | 防火可燃性、可燃性试验 |

   仅有「试验」二字增减的差异（如「防水性」与「防水性试验」）一律视为同一试验。名称差异大到在上表中无法归位，判 Review 并列出两处名称。
3. 核查「表中有、正文无」。一览表中列出但正文找不到对应章节的项目，判 Fail，并逐个写明：**序号、项目名称、一览表所载类别**。注意：若该项目在一览表中标注为不开展、N/A 或类别 X，按规则 QTP-LIST-04 处理，不在本项判 Fail。
4. 核查「正文有、表中无」。正文中存在的试验章节，若在一览表中找不到对应行，判 Fail 并逐个写明：**章节号、章节标题**。这意味着一览表漏列，或该试验未经策划就写进了大纲。
5. 核查同一章承载多行的情形。一览表中同一标准章的多个子项常拆成多行，它们共同对应正文的同一章。**这种情形下每一行仍须单独输出核对结果**，并在对应章内确认该子项确有独立描述——只写章名不算对应。
6. 核查一对多的情形。若一览表某一行对应正文的多个章节（同一试验被拆成多章，例如持续加速度单独成章），或多行对应同一章节，须在结论中说明该对应关系是否合理。无法判断合理性判 Review。
7. 输出核对统计。最后输出：**一览表总行数、已对应行数、未对应行数、正文多出的章节数**。四个数字必须给出，用于验证逐行核对确实覆盖了全表。

### 原子检查项

- 检查项编号：QTP-LIST-02-C001
  检查项：是否对一览表每一行都在正文定位了承载该试验的章节
  通过标准：未对应的行逐条展开写明序号与项目名称，已对应的行按序号列出

- 检查项编号：QTP-LIST-02-C002
  检查项：判定名称对应时是否采用了规范名称与常见别名的对照
  通过标准：仅「试验」二字增减视为同一试验；差异大到无法在对照表中归位的判 Review 并列出两处名称

- 检查项编号：QTP-LIST-02-C003
  检查项：一览表列出但正文找不到对应章节的项目是否已逐个列出
  通过标准：逐个写明序号、项目名称、一览表所载类别；标注不开展或类别 X 的行不在本项判 Fail

- 检查项编号：QTP-LIST-02-C004
  检查项：正文存在但一览表未列出的试验章节是否已逐个列出
  通过标准：逐个写明章节号与章节标题

- 检查项编号：QTP-LIST-02-C005
  检查项：同一标准章拆成多行的子项是否每行都单独输出核对结果
  通过标准：每行单独输出，并在对应章内确认该子项确有独立描述，只写章名不算对应

- 检查项编号：QTP-LIST-02-C006
  检查项：一行对应多章或多行对应同一章时是否说明了对应关系的合理性
  通过标准：已说明合理性；无法判断合理性判 Review

- 检查项编号：QTP-LIST-02-C007
  检查项：是否输出一览表总行数、已对应行数、未对应行数、正文多出章节数
  通过标准：四个数字全部给出，且可用于验证逐行核对覆盖了全表

## 03. 试验类别的逐行比对

- 规则编号：QTP-LIST-03
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,试验类别
- 规则说明：以一览表的试验类别列为基准，逐行与对应章节正文比对，并核查类别取值是否属于该试验的合法范围。

### 审查内容

以一览表所载各行的试验类别为基准，在对应试验章节正文中找出类别声明并逐行比对，同时核查类别取值合法性。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 逐行提取基准类别。**对一览表的每一行**，提取其试验类别取值。类别列为空或标注为「/」的行，须在结论中单独列出并说明其为何无类别（如非 DO-160G 项目、或由其它文件规定）。
2. 逐行比对章节内类别。到该行对应的试验章节正文中查找类别声明（通常在章节开头的试验要求、试验条件或试验条件表中），与基准比对。按分层要求输出：**不一致的行逐条展开**，写明「序号N 项目名称：一览表 X类，第Y章正文 Z类」；**一致的行只列序号**（如「类别一致：序号 1、3、4、8~14」），一致行不超过 10 行时可展开。
3. 判定不一致。类别代号不同即判不一致，判 Fail，并逐个写明：**序号、项目名称、章节号、一览表所载类别、章节正文所载类别**。举例：一览表载温度和高度为 A2 类，而对应章节正文写 A1 类，即为不一致，须明确列出。
4. 核查类别取值是否合法。**对每一行**，用下表核查其类别取值是否属于该试验的合法范围。**各试验的类别体系互不相同，把一个试验的类别用到另一个试验上是常见错误**：

   | 标准章 | 试验项目 | 合法类别取值 |
   |---|---|---|
   | 第4章 | 温度－高度 | A1、A2、A3、A4、B1、B2、B3、B4、C1、C2、C3、C4、D1、D2、D3、E1、E2、F1、F2、F3；冷却能力损失另有时间类别 V、W、P、Y、Z |
   | 第5章 | 温度变化 | A、B、C、S1、S2 |
   | 第6章 | 湿热 | A、B、C |
   | 第7章 | 工作冲击和坠撞安全 | A（仅标准工作冲击）、B（标准工作冲击＋坠撞安全）、D（仅低频工作冲击）、E（低频工作冲击＋低频坠撞安全） |
   | 第8章 | 振动 | S（标准振动）、R／U／U2（强化振动）、H／Z（短时高量级振动） |
   | 第9章 | 爆炸大气 | A、E、H |
   | 第10章 | 防水性 | X、Y、W、R、S |
   | 第11章 | 流体敏感性 | F |
   | 第12章 | 砂尘 | D（吹尘）、S（吹砂和吹尘） |
   | 第13章 | 霉菌 | F |
   | 第14章 | 盐雾 | S（盐雾）、T（严酷盐雾） |
   | 第15章 | 磁影响 | Y（D＝0.0m）、Z（0＜D≤0.3m）、A（0.3m＜D≤1m）、B（1m＜D≤3m）、C（D＞3m），D 为罗盘偏转 1° 时罗盘与设备的距离 |
   | 第16章 | 电源输入 | 交流 A(CF)／A(NF)／A(WF)，直流 A／B／D／Z；其后附加试验标识字母：交流谐波 H／X、电流调制 L／Z、功率因数 P／Z、冲击电流 I／Z／X；直流电流脉动 R／X、冲击电流 I／Z／X |
   | 第17章 | 电压尖峰 | A、B |
   | 第18章 | 音频传导敏感度 | 交流 R(CF)／R(NF)／R(WF)，直流 R／B／Z，另有 K 类 |
   | 第19章 | 感应信号敏感度 | 三字母：第1位 C／Z／A／B，第2位 C／N／W，第3位 E／X |
   | 第20章 | 射频敏感度 | 双符号，各位取 B／D／F／G／L／M／O／R／S／T／W／Y／Q（第1位传导、第2位辐射） |
   | 第21章 | 射频能量发射 | B、L、M、H、P、Q |
   | 第22章 | 雷电感应瞬态敏感度 | 六字符：第1位 A／B／Z／X，第2位 1~5／Z／X，第3位 C~K／Z／X，第4位 1~5／Z／X，第5位 L~M／Z／X，第6位 1~5／Z／X；全不做记 XXXXXX |
   | 第23章 | 雷电直接效应 | 四字符：前2位高压附着、后2位大电流，各取 1A／1B／1C／2A／2B／3N；不做记 XX，非标准波形或配置记 ZZ；全不做记 XXXX |
   | 第24章 | 结冰 | A、B、C |
   | 第25章 | 静电放电 | A |
   | 第26章 | 防火，可燃性 | A（防火）、B（耐火）、C（可燃性） |

   某行的类别不在该试验的合法取值内，判 Fail 并写明：序号、项目名称、错用的代号、该试验的合法取值范围。举例：温度变化的合法类别为 A、B、C、S1、S2，写成「A2 类」即为错用——A2 属温度－高度的类别体系。
5. 核查通用类别 X。**类别 X 可与任一试验一起使用**，表示设备供应商不打算就该试验条件验证符合性（保留备用）。标注 X 的行不判为类别错误，但须核查大纲是否说明该项不验证；未说明判 Review。
6. 核查组合式类别的位数。感应信号敏感度为**三字母**、射频敏感度为**双符号**、雷电感应瞬态为**六字符**、雷电直接效应为**四字符**、电源输入为**基本类别＋试验标识字母**。位数不足或多余，判 Fail 并写明应为几位、实为几位。
7. 核查章节内类别缺失。对应章节正文完全未声明试验类别的，判 Fail 并写明章节号与项目名称——该章全部数值判据将因此失去比对基准。
8. 核查章节内多处类别自洽。同一试验章节内，类别可能在试验要求、试验条件表、试验程序、合格判据等多处出现，这些出现处必须**互相一致**。同一章内出现两个不同类别代号，判 Fail 并列出该章内各处取值及其位置。
9. 核查子项共享类别的情形。一览表中同一标准章的多个子项行，其类别可能只在首行标注、后续行留空（表示沿用）。这种情形下应视为各子项共享该类别，须核查对应章节内各子试验是否都按该类别取值。某子试验用了不同类别且无说明，判 Fail。
10. 输出核对统计。最后输出：**已比对行数、一致行数、不一致行数、类别取值非法的行数、章节内无类别声明的行数**。

### 原子检查项

- 检查项编号：QTP-LIST-03-C001
  检查项：是否对一览表每一行提取了试验类别取值
  通过标准：类别列为空或标注为「/」的行单独列出并说明其为何无类别

- 检查项编号：QTP-LIST-03-C002
  检查项：是否将每行基准类别与对应章节正文的类别声明作了比对
  通过标准：不一致的行逐条展开写明两处取值，一致的行按序号列出

- 检查项编号：QTP-LIST-03-C003
  检查项：类别不一致的行是否逐个写明了两处取值
  通过标准：写明序号、项目名称、章节号、一览表所载类别、章节正文所载类别

- 检查项编号：QTP-LIST-03-C004
  检查项：各行类别取值是否属于该试验的合法范围
  通过标准：对照各试验的类别体系核查；把一个试验的类别用到另一个试验上判 Fail 并写明合法取值范围

- 检查项编号：QTP-LIST-03-C005
  检查项：标注类别 X 的行大纲是否说明了该项不验证
  通过标准：有说明；未说明判 Review。标注 X 本身不判为类别错误

- 检查项编号：QTP-LIST-03-C006
  检查项：组合式类别的位数是否正确
  通过标准：感应信号敏感度三字母、射频敏感度双符号、雷电感应瞬态六字符、雷电直接效应四字符、电源输入基本类别加试验标识字母

- 检查项编号：QTP-LIST-03-C007
  检查项：对应章节正文是否声明了试验类别
  通过标准：各对应章节均有类别声明；完全未声明判 Fail 并写明章节号与项目名称

- 检查项编号：QTP-LIST-03-C008
  检查项：同一试验章节内多处出现的类别代号是否互相一致
  通过标准：试验要求、试验条件表、试验程序、合格判据等处取值一致；出现两个不同代号判 Fail 并列出各处位置

- 检查项编号：QTP-LIST-03-C009
  检查项：子项行留空沿用首行类别时对应章节各子试验是否按同一类别取值
  通过标准：各子试验按同一类别；某子试验用了不同类别且无说明判 Fail

- 检查项编号：QTP-LIST-03-C010
  检查项：是否输出五项类别核对统计
  通过标准：给出已比对行数、一致行数、不一致行数、类别取值非法行数、章节内无类别声明行数

## 04. 开展状态与豁免项的逐行核查

- 规则编号：QTP-LIST-04
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,相似性分析
- 规则说明：逐行核查一览表标注的开展状态与正文安排是否吻合，判定漏项前先排除合法豁免。

### 审查内容

以一览表的开展状态标识为基准，逐行核查正文中该试验的实际安排是否与之吻合。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 逐行提取开展状态。**对一览表的每一行**，提取其开展状态（「开展」「不开展」「N/A」「以相似性分析替代」或等效表述）。按分层要求输出：**标注不开展、N/A、相似性分析替代的行逐条展开**；**标注开展的行只列序号**。
2. 核查标注开展的行。标注为**开展**的行，正文必须有对应章节且该章有实质试验描述（含试验条件、试验程序、试验判据中至少一项具体内容）。判“无实质描述”前必须检索该项目对应章节的全部小节、条件表、程序表和判据，不得因试验概览表或某一张条件表未单列该项目就判缺失。仅有章节标题而全章确无实质内容，才判 Fail，并写明序号、项目名称、章节号及已检索范围。
3. 核查标注不开展的行。标注为**不开展或 N/A** 的行，不要求再设置该子试验的独立条件、程序或判据；须核查两点：一是正文或试验项目一览表是否明确给出不开展结论；二是是否给出了不开展的**依据**。有不开展结论且依据充分判 Pass；**有不开展结论而无依据，判 Fail**，但问题应写成“缺少不开展依据”，不得写成“缺少试验程序”；一览表与正文均未提及该项目判 Review。
4. 判定「该做未做」前，先对照以下 DO-160G 认可的**合法豁免与替代情形**，属于其中之一且有依据的判 Pass，不判漏项：

   - **类别标注为 X**：X 类表示不就该试验条件验证符合性，正文不安排该试验是允许的；
   - **短时工作温度与工作温度相同**：可不做低温／高温短时工作试验，但地面耐受试验不可取消；
   - **非 A 类设备（温度－高度）**：不做减压试验与过压试验；
   - **已在音频传导敏感度试验中完成的电源线**：不再做感应信号敏感度试验；
   - **材料全部为非营养材料**：霉菌试验可用材料成分证明或既往试验证明替代，但须在环境合格鉴定书中说明；
   - **设备非强迫风冷、或冷却失效不影响持续安全飞行和着陆**：不做飞行中冷却能力损失试验；
   - **设备为内部安装（非外部安装）**：可不做雷电直接效应试验；
   - **以相似性分析替代**：须给出相似性分析的依据文件或结论出处。

   属上述情形但**未给出依据**的，判 Fail；不属上述任一情形而缺失的，判 Fail 并写明缺失的项目名称。
5. 核查状态矛盾。一览表标注开展、正文却说明不做，或一览表标注不开展、正文却安排了完整试验，均判 Fail 并逐个写明：**序号、项目名称、一览表标注、正文实际安排**。
6. 核查试件分配一致。若一览表备注列标注了试件分配（如「试件1/试件2」「试件2」），核查其与试验顺序说明、预期试验周期表中的试件安排是否一致。不一致判 Fail 并列出冲突位置；某项目未分配任何试件判 Review。
7. 输出核对统计。最后输出：**标注开展的行数、标注不开展的行数、合法豁免且有依据的行数、缺依据的不开展行数、状态与正文矛盾的行数**。

### 原子检查项

- 检查项编号：QTP-LIST-04-C001
  检查项：是否对一览表每一行提取了开展状态
  通过标准：标注不开展、N/A、以相似性分析替代的行逐条展开，标注开展的行按序号列出

- 检查项编号：QTP-LIST-04-C002
  检查项：标注开展的行正文是否有实质试验描述
  通过标准：含试验条件、试验程序、试验判据中至少一项具体内容；判无实质描述前已检索该章全部小节、条件表、程序表和判据

- 检查项编号：QTP-LIST-04-C003
  检查项：标注不开展或 N/A 的行是否给出不开展结论与依据
  通过标准：有结论且依据充分；有结论无依据判 Fail 且问题写成「缺少不开展依据」而非「缺少试验程序」；表与正文均未提及判 Review

- 检查项编号：QTP-LIST-04-C004
  检查项：判定该做未做前是否对照了 DO-160G 认可的合法豁免与替代情形
  通过标准：属合法豁免且有依据判 Pass；属豁免但未给出依据判 Fail；不属任一情形而缺失判 Fail 并写明项目名称

- 检查项编号：QTP-LIST-04-C005
  检查项：一览表标注的开展状态与正文实际安排是否矛盾
  通过标准：不存在表标开展而正文说明不做、或表标不开展而正文安排完整试验的情形

- 检查项编号：QTP-LIST-04-C006
  检查项：备注列的试件分配是否与试验顺序说明及预期试验周期表一致
  通过标准：三处一致；不一致判 Fail 并列出冲突位置，某项目未分配任何试件判 Review

- 检查项编号：QTP-LIST-04-C007
  检查项：是否输出五项开展状态统计
  通过标准：给出标注开展行数、标注不开展行数、合法豁免且有依据行数、缺依据的不开展行数、状态与正文矛盾行数

## 05. 引用标准条款与章节内容的逐行对应

- 规则编号：QTP-LIST-05
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,引用标准
- 规则说明：逐行核查一览表所引标准条款与项目名称、章节内容是否吻合。

### 审查内容

以一览表的引用标准条款列为基准，逐行核查对应章节所描述的试验程序是否与之相符。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 逐行提取引用条款。**对一览表的每一行**，提取其引用标准条款（如「RTCA/DO-160G 第4章 第4.5.1条」）。按分层要求输出：**条款与项目不自洽、或条款列为空的行逐条展开**；**自洽的行只列序号**。
2. 核查条款所属章与项目名称是否自洽。用下表核查所引章号与项目名称是否匹配：第4章＝温度－高度，第5章＝温度变化，第6章＝湿热，第7章＝工作冲击和坠撞安全，第8章＝振动，第9章＝爆炸大气，第10章＝防水性，第11章＝流体敏感性，第12章＝砂尘，第13章＝霉菌，第14章＝盐雾，第15章＝磁影响，第16章＝电源输入，第17章＝电压尖峰，第18章＝音频传导敏感度，第19章＝感应信号敏感度，第20章＝射频敏感度，第21章＝射频能量发射，第22章＝雷电感应瞬态敏感度，第23章＝雷电直接效应，第24章＝结冰，第25章＝静电放电，第26章＝防火可燃性。章号与项目名称对不上，判 Fail 并写明序号、所引章号、项目名称。
3. 核查条款细分号与子试验是否自洽。温度－高度章的条款细分为：4.5.1＝地面低温耐受和低温短时工作，4.5.2＝低温工作，4.5.3＝地面高温耐受和高温短时工作，4.5.4＝高温工作，4.5.5＝飞行中冷却能力损失，4.6.1＝高度，4.6.2＝减压，4.6.3＝过压。所引细分条款与该行的子试验名称不符，判 Fail 并写明。例如引用 4.5.2 却写「地面低温耐受试验」即为不符。
4. 核查条款与章节内容是否相符。对应章节所描述的试验程序，应与所引条款规定的试验是同一件事。章节实际做的试验与所引条款明显不是同一件事，判 Fail 并写明差异。
5. 核查非标准项目。一览表中引用非 DO-160G 依据的行（如引用主机厂要求、其它标准），须核查正文对应章节是否说明了该依据的出处与要求。未说明判 Fail 并写明序号与项目名称。
6. 核查版本一致。全表所引标准的版本（如 DO-160G）应与引用文件章所列版本一致。出现不同版本，判 Fail 并列出各处取值。
7. 输出核对统计。最后输出：**已核对行数、章号与项目自洽的行数、不自洽行数、非标准依据行数**。

### 原子检查项

- 检查项编号：QTP-LIST-05-C001
  检查项：是否对一览表每一行提取了引用标准条款
  通过标准：条款与项目不自洽或条款列为空的行逐条展开，自洽的行按序号列出

- 检查项编号：QTP-LIST-05-C002
  检查项：所引标准章号与项目名称是否自洽
  通过标准：对照 DO-160G 第 4~26 章的章号与项目名称对应关系核查；对不上判 Fail 并写明序号、所引章号、项目名称

- 检查项编号：QTP-LIST-05-C003
  检查项：所引条款细分号是否与该行的子试验名称相符
  通过标准：如 4.5.1 对应地面低温耐受和低温短时工作、4.5.2 对应低温工作；引错判 Fail 并写明

- 检查项编号：QTP-LIST-05-C004
  检查项：对应章节所描述的试验程序是否与所引条款是同一件事
  通过标准：两者一致；明显不是同一件事判 Fail 并写明差异

- 检查项编号：QTP-LIST-05-C005
  检查项：引用非 DO-160G 依据的行正文是否说明了该依据的出处与要求
  通过标准：已说明；未说明判 Fail 并写明序号与项目名称

- 检查项编号：QTP-LIST-05-C006
  检查项：全表所引标准的版本是否与引用文件章所列版本一致
  通过标准：版本完全一致；出现不同版本判 Fail 并列出各处取值

- 检查项编号：QTP-LIST-05-C007
  检查项：是否输出四项条款核对统计
  通过标准：给出已核对行数、章号与项目自洽行数、不自洽行数、非标准依据行数

## 06. 子试验项目在对应章节中的落实

- 规则编号：QTP-LIST-06
- 规则类型：文档级
- 文档类型：环境鉴定试验大纲
- 关键词：试验项目一览表,试验程序
- 规则说明：核查各试验按标准应含的子试验是否齐全，且每个子试验在对应章节中都有独立描述。

### 审查内容

对照标准应含的子试验清单，核查一览表覆盖是否齐全，以及各子试验在对应章节中是否有独立描述。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 对照下表核查子试验齐全性。**对一览表涉及的每一个标准章**，核查其子试验是否齐全：

   | 标准章 | 按标准应含的子试验 |
   |---|---|
   | 第4章 温度－高度 | 地面低温耐受和低温短时工作试验、低温工作试验、地面高温耐受和高温短时工作试验、高温工作试验、飞行中冷却能力损失试验、高度试验、减压试验、过压试验（共 8 项） |
   | 第5章 温度变化 | 温度变化试验（A/B/C 类走温度变化程序；S1/S2 类走温度冲击程序） |
   | 第6章 湿热 | 湿热试验 |

   | 第8章 振动 | 标准振动试验、强化振动试验、短时高量级振动试验（直升机设备只做强化振动） |

   其余各章（第13、14、15、17、24、25 章）为单一试验，无子试验细分。核查某子试验是否缺失时，必须先读取一览表开展状态：明确标注“不开展/N/A/类别X/以相似性分析替代”的子试验，不纳入“必须有独立描述”的数量，其依据充分性转由 QTP-LIST-04 判定；只有标注开展或未给出任何豁免状态的子试验，才继续判定正文是否缺失。
2. 逐子项核查独立描述。对一览表标注**开展**或未给出合法豁免状态的每一个子试验，必须在对应章节中有独立的实质试验描述——须含试验条件、试验程序、试验判据中的至少一项具体内容。判缺失前必须检索对应章节全部小节、表格和图题，不得因概览表或某一张条件表未列出就下结论。按分层要求输出：**全章检索后仍未找到独立描述的子试验逐条展开**，写明所属章节、子试验名称与检索范围；**有独立描述的只列名称**，不展开。仅在章节开头罗列子项名称、全章正文无对应内容，才判 Fail。
3. 核查跨章编排的子项。某些子试验可能被单独编排为独立章节（例如坠撞安全持续加速度独立成「加速度试验」章、风车振动独立成章）。判定子项缺失前，**必须先在全文章节目录中确认该子项是否已单独成章**。已单独成章的，在原章判为不适用并注明其所在章节号；同时**必须核查那个独立章节是否有实质内容**——独立章节存在却无实质描述，仍判 Fail。
4. 核查子项顺序。章节内各子试验的描述顺序，宜与一览表中的行顺序一致。顺序不一致判 Review 并说明（顺序差异通常不影响符合性，但可能提示遗漏）。
5. 核查子项的类别继承。子试验行的类别若在一览表中留空（沿用首行），对应章节内各子试验应按同一类别取值。某子试验用了不同类别且无说明，判 Fail。
6. 核查正文多出的子试验。对应章节中描述了一览表未列出的子试验，判 Review 并写明章节号与子试验名称——可能是一览表漏列，也可能是超范围试验。
7. 输出核对统计。最后输出：**按标准应含的子试验总数、一览表已列出数、有独立描述数、缺失数、已单独成章数、合法豁免数**。

### 原子检查项

- 检查项编号：QTP-LIST-06-C001
  检查项：一览表涉及的各标准章其子试验是否齐全
  通过标准：对照按标准应含的子试验清单核查；标注不开展、N/A、类别 X 或以相似性分析替代的子试验不纳入必须有独立描述的数量

- 检查项编号：QTP-LIST-06-C002
  检查项：标注开展或无合法豁免的子试验在对应章节是否有独立实质描述
  通过标准：含试验条件、试验程序、试验判据中至少一项；判缺失前已检索该章全部小节、表格和图题

- 检查项编号：QTP-LIST-06-C003
  检查项：判定子项缺失前是否确认了该子项未单独成章
  通过标准：已单独成章的在原章判不适用并注明所在章节号，同时核查该独立章节确有实质内容

- 检查项编号：QTP-LIST-06-C004
  检查项：章节内各子试验的描述顺序是否与一览表行顺序一致
  通过标准：顺序一致；不一致判 Review 并说明

- 检查项编号：QTP-LIST-06-C005
  检查项：留空沿用首行类别的子试验对应章节是否按同一类别取值
  通过标准：各子试验按同一类别；某子试验用了不同类别且无说明判 Fail

- 检查项编号：QTP-LIST-06-C006
  检查项：对应章节是否描述了一览表未列出的子试验
  通过标准：无多出的子试验；有则判 Review 并写明章节号与子试验名称

- 检查项编号：QTP-LIST-06-C007
  检查项：是否输出六项子试验统计
  通过标准：给出按标准应含子试验总数、一览表已列出数、有独立描述数、缺失数、已单独成章数、合法豁免数
