# 风车环境（短时高量级振动）试验大纲审查规则

> 本文件序号 28 是规则目录组织号，不是 DO-160G 标准章号。风车环境对应发动机风扇叶片受损产生的短时高量级振动，标准判据来源于 DO-160G 第8章 8.2.1.3、8.3、8.4.1.1 和 8.6；型号项目的具体量值还应与《风车环境QTP评估检查单》所引用的企业标准最新有效版次一致。
>
> 本文件第 1～5 条沿用各试验章节的测试设备/系统规则；第 6～13 条对应《风车环境QTP评估检查单—标注》E列标为“试验章节”的设备安装、测点、扫频、量值、程序、试验要求、合格判据和前中后状态记录。E列标为“通用”的类别、设备描述和试验报告记录要求不在本文件重复设置。

### 审查内容

## 09. 三轴正弦扫频范围、速率与次数

- 规则编号：QTP-WMV-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：风车振动,风车环境
- 规则说明：核查三个正交轴的正弦线性扫频、频率范围、扫描速率和次数。

### 审查内容

核查X/Y/Z轴向、工作状态、最低/最高频率、线性扫频率和扫频次数。

### 审查步骤

> **判定约束**：先检索当前章全文、表图及有效引用，判缺失须写明检索范围。evidence 必须是可搜索原文并逐项支撑结论，禁止臆造。只比较同一对象、字段和条件；`XXX`、`TBD`、`待定`、`待补充`不算填写，`N/A`、`/`、`-`仅表状态，依据另审。逐项查全；同一缺陷只报一次；建议须保持原意且可直接采用。

1. 设备应处于工作状态，在飞机机体/设备三个正交轴的每一轴向进行正弦振动；缺轴向或非工作状态判 Fail。
2. **H类**每轴以不超过 **0.167Hz/s** 的速率，从 **10Hz线性扫频到250Hz，进行1次扫频**；范围、速率或次数不符判 Fail。
3. **Z类**可降低最高频率，但最高频率须不低于最大风扇转子速率的2倍；缺最大转子速率和计算关系判 Fail。
4. 企业标准若要求更严的频率范围、扫频率、次数或时间，应按更严要求核查；未给有效版次无法比较判 Review。

### 审查内容

核查试验前检查、安装与测点确认、工作模式、逐轴扫频、过程监测、异常处置和试验后检查。

### 审查步骤

4. 发生功能异常、失控或超差时应有中止、记录和恢复处理；完全未规定判 Review。
