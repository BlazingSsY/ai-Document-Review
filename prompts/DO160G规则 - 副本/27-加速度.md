# 加速度环境试验大纲审查规则

> 本文件序号 27 是规则目录组织号，不是 DO-160G 标准章号。加速度环境未作为 DO-160G 独立章节列出；本文件以《加速度环境QTP评估检查单》为检查项框架，标准判据取自 DO-160G 第7章 7.3.3 持续载荷程序。型号项目另有企业标准或设备规范时，类别、功能加速度和结构加速度的最终量值还必须与其最新有效版次一致。
>
> 本文件第 1～5 条沿用各试验章节的测试设备/系统规则；第 6～10 条对应《加速度环境QTP评估检查单-标注》E列标为“试验章节”的试验件安装、试验载荷、试验步骤/精度和合格判据。E列标为“通用”的类别、描述、构型和记录要求不在本文件重复设置。

---

## 01. 本章测试设备名称及型号

- 规则编号：QTP-ACC-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查加速度试验章节是否逐台列出全部测试设备的可识别名称和具体型号。

### 审查内容

核查本章使用的离心机、火箭撬、静力加载装置、夹具、加速度测量/控制系统及功能检测设备是否逐台给出名称和型号，并与程序对应。

### 审查步骤

1. 核查设备清单。当前章应列出实际使用的全部加载、控制、测量、监测和功能检测设备；完全未提供设备信息判 Fail。
2. 逐台核查名称和型号。通用名称而无具体型号，或名称/型号为占位文本，判 Fail 并列明设备。
3. 核查清单与程序对应。程序中出现但清单未列出的离心机、加载装置、传感器、控制器或功能检测设备，判 Fail。
4. 本试验不可能以“无需专用测试设备”为由整体豁免；采用静态力替代离心机时，仍须列出加载与测量设备。

## 02. 本章测试设备完整性与数量

- 规则编号：QTP-ACC-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查设备配置和数量是否覆盖六方向加载、控制、测量、功能检测及记录需求。

### 审查内容

核查设备配置能否覆盖载荷产生、方向转换、载荷控制、加速度/力测量、计时、受试设备状态监测、功能检测和数据记录。

### 审查步骤

1. 建立“必需功能—承担设备—设备数量”的对应表；只列设备名称而无数量，判 Fail。
2. 若通过离心机实施，应能完成规定半径/转速控制、方向转换和时间保持；通过静态力实施，应能通过受试设备重心施加载荷并测量实际力值。
3. 缺少任一必需功能的设备，或数量不足以完成声明的多点控制/监测方案，判 Fail。
4. 无法从现有参数确认能力时判 Review，不得凭设备名称推断其能力。

## 03. 本章测试设备关键参数与能力比较

- 规则编号：QTP-ACC-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查加载和测量设备的量程、精度及持续能力是否覆盖最大加速度/静力载荷和保载时间。

### 审查内容

核查离心机半径与转速范围、最大加速度和载荷能力，静力装置力值范围，加速度计/力传感器量程与精度，计时和采集能力。

### 审查步骤

1. 逐台识别决定试验能力的关键参数；缺最大载荷/加速度、量程或精度等决定性参数判 Fail。
2. 必须形成“载荷方向及要求值—设备声明能力—比较结论”的逐项证据链。设备能力低于最大试验值、量程不能覆盖或精度宽于大纲/型号规范要求，判 Fail。
3. 离心机程序应给出足以计算试验加速度的半径和转速控制能力；静态力程序应说明力值测量与受试设备重心加载能力。缺失判 Review。
4. 只有设备参数而没有与功能/结构加速度载荷的比较，不得判 Pass。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-ACC-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查需校准设备的周期、有效期和试验时有效状态，并明确无需校准设备及依据。

### 审查内容

核查加速度计、力传感器、转速/半径测量、计时和数据采集设备的校准有效性。

### 审查步骤

1. 逐台识别需校准和无需校准的设备；未作区分判 Review，无需校准但无理由判 Review。
2. 需校准设备应给出周期、有效期截止日期或可追溯到试验日期的证书信息；完全缺失判 Fail。
3. 仅写“定检”“设备校验”“已校准”等泛化状态而无法确认试验日处于有效期内，判 Fail。
4. 校准资料不可读或未随证据提供时判 Review，并指出设备及待核资料。

## 05. 本章测试设备替代方案

- 规则编号：QTP-ACC-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查替代设备的量程、精度、持续载荷和安全能力是否等同或优于原设备。

### 审查内容

核查大纲是否规定加载和测量设备替代条件，并保证替代后仍满足本章全部载荷与测量要求。

### 审查步骤

1. 允许替代时，应明确量程、精度、持续加载能力和其他关键能力等同或更优；条件缺失判 Fail。
2. 替代后仍应满足最大功能/结构载荷、保载时间、方向控制和校准有效性；无法证明判 Review。
3. 完全未规定替代方案判 Review；不得据此虚构替代设备。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 试验件安装与载荷施加方式

- 规则编号：QTP-ACC-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查安装方式、夹具、方向和加载方式能否代表机上安装及正确惯性载荷。

### 审查内容

核查试验件安装图/文字、刚性夹具、实际安装连接件、飞机轴向，以及离心机/火箭撬/静力加载方式。

### 审查步骤

1. 应以图示或文字给出安装方式和方向，并能代表机上安装状态；完全缺失判 Fail。
2. 应采用刚性试验夹具和实际安装方法固定设备或模拟负载，安装连接件应具有代表性；不一致无说明判 Fail。
3. 静态力替代仅在其他部件脱落仍能保持在机箱内部时可接受，且应通过受试设备重心施加载荷；条件未证明判 Review，通过非重心位置加载判 Fail。
4. 持续载荷方向与惯性加速度 g 方向相同；静态力方向宜与 g 方向一致；离心机加速度方向与要求的载荷方向相反，必须通过设备朝向保证实际惯性载荷方向正确。方向颠倒判 Fail。

## 07. 功能与结构加速度试验载荷

- 规则编号：QTP-ACC-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查各飞机方向的功能和结构加速度载荷是否满足项目标准及DO-160G持续载荷最低要求。

### 审查内容

核查上、下、前、后、左、右六方向的功能/结构载荷、F/R类型和项目标准出处。

### 审查步骤

1. 大纲应逐方向列出项目要求的**功能加速度载荷**和**结构加速度载荷**；只给单一总值或未区分功能/结构载荷判 Fail。
2. 若以 DO-160G 表7-1作为最低持续载荷依据，量值（上/下/前/后/侧向，单位g）为：直升机 F=4/20/16/NA/8、R=20/20/20/20/20；固定翼运输机 F=3/6/9/1.5/4、R=9/9/9/9/9；固定翼非运输机 F=3/NA/18/NA/4.5、R=18/18/18/18/18；所有固定翼飞机 F=3/6/18/1.5/4.5、R=18/18/18/18/18；直升机和所有固定翼飞机 F=4/20/18/1.5/8、R=20/20/20/20/20。侧向同时覆盖左、右。
3. 大纲值低于适用机型和 F/R 类型的最低值，判 Fail，并逐方向写明“要求值—实际值”；项目企业标准要求更严时按更严值核查。
4. 安装方向未知或不固定却采用 F 值，判 Fail；采用项目标准但未提供类别/区域到载荷值的追溯证据，判 Review。

## 08. 试验程序、方向与保载时间

- 规则编号：QTP-ACC-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查六方向加载、至少3秒保载、载荷控制和功能监测程序是否完整可执行。

### 审查内容

核查试验前检查、安装、方向切换、升载、稳载、保载、卸载、功能检查和最终检查步骤。

### 审查步骤

1. 对每个适用载荷方向应至少保持规定载荷 **3s**；短于3s或未写明判 Fail。项目标准要求更长时按更长时间核查。
2. 已知安装方向时按飞机主正交轴确定载荷量值和设备方向；方向未知或不固定时应按设备三个正交轴的每一方向采用 R 类量值。六方向缺任一方向判 Fail。
3. 程序应说明逐渐升载、达到要求值后的稳定/计时起点、保持、卸载和方向转换；无法据以执行判 Fail。
4. 若分功能载荷和结构载荷阶段，应分别说明设备工作状态、功能监测方法和结构检查时机；只给载荷表而无实施步骤判 Fail。
5. 应规定实际载荷和保载时间的测量记录；只记录设备设定值而不验证实际值判 Review。

## 09. 试验测量精度与载荷控制

- 规则编号：QTP-ACC-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查测试精度、载荷控制和方向定义是否满足项目标准并能证明实际载荷符合要求。

### 审查内容

核查加速度/力值、时间、转速和方向的测量精度与控制方法。

### 审查步骤

1. 应明确项目企业标准对加速度/力值、保载时间和其他测量的精度要求；未给数值且无法从有效引用获得时判 Review。
2. 应说明实际加速度或静力值的测量位置、控制通道和记录方式；只给离心机转速或设备设定值而无实际载荷验证判 Review。
3. 采用离心机时应考虑半径、转速以及旋转加速度和加速度增长率对试件的影响；适用但未评估判 Review。
4. 测量精度宽于项目标准、量程不足或控制偏差导致实际载荷不能满足规定值，判 Fail。

## 10. 功能与结构完整性合格判据

- 规则编号：QTP-ACC-10
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：加速度试验,加速度环境
- 规则说明：核查判据是否覆盖功能正常、具体检测方法和安装/结构完整性。

### 审查内容

核查功能加速度阶段的性能符合性和结构加速度阶段的结构/安装连接件完整性判据。

### 审查步骤

1. 应明确试验前、功能载荷期间/每方向后及试验后的具体功能检测项目、方法和允许限值；仅写“功能正常”判 Review，完全无功能判据判 Fail。
2. 电子设备若要求载荷期间保持工作，应明确供电、工作模式、监测参数和失效判定；只写“通电”而无检测方法判 Review。
3. 持续载荷完成六方向加载后，允许弯曲与变形，但**安装连接件不应破坏，设备或模拟负载应保持在原位**；与此冲突判 Fail。
4. 项目标准若对结构损伤、永久变形或性能漂移规定更严判据，应同时满足；只引用标准而不展开可判条件判 Review。
