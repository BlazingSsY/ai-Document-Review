# DO-160G 第8章 振动 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到振动章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-08-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-08-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-08-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-08-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-08-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 振动试验前通用准备

- 规则编号：QTP-DO160G-08-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查安装方式、夹具、测点布置、控制方式与测量精度是否符合通用要求。

### 审查内容

核查安装方式、夹具、测点布置、控制方式与测量精度是否符合通用要求。

### 审查步骤

1. 核查安装与夹具。设备安装应确保**输入振动运动的方向平行于三个主正交轴之一**；试验夹具的**刚性和对称性应与实际情况一样**；设备应按设备规范规定的方式连接在夹具或振动台台面上；**外部装有减振器/缓冲器的设备应装上减振器/缓冲器进行试验**。缺安装信息（图示或文字）判 Fail；装有减振器却未说明是否装上判 Review。
2. 核查安装方式的代表性。安装方式应可代表机上安装状态，文档未说明与机上一致性判 Review。
3. 核查响应测点。应在受试设备上安装加速度计以测量记录规定轴向的振动响应，**确定共振频率和放大系数**；安装位置可包括主要结构、印制电路板、大的元件和模块。缺测点布置方案判 Fail。
4. 核查控制测点与多点控制方式。每一试验轴向的**控制加速度计应安装在试验夹具上尽可能靠近设备安装点**的位置；使用多个加速度计控制量级时，**正弦试验取各控制信号的平均值，随机试验取各 APSD 信号的平均值**；应使用谱图或 APSD 图验证控制量级。测点未体现"靠近安装点"判 Review；多点控制未说明取平均值判 Review。
5. 核查测量精度。测量正弦加速度的仪器系统精度应为**加速度 ±10%、频率 ±2%**。未写明或宽于该值判 Fail。
6. 核查降量级情形。检查单条目：设备质量较大需降低试验量级时，应给出**设备质量（kg）与降低后的试验载荷（g）**。声明需降量级却未给出这两个数值判 Fail；降量级但未给出依据判 Review。

## 07. 振动试验量级容差

- 规则编号：QTP-DO160G-08-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查试验量级的控制容差是否与规定一致。

### 审查内容

核查试验量级的控制容差是否与规定一致。

### 审查步骤

1. 核对正弦控制容差。在规定频率范围内，加速度试验量级的控制值应限制在**规定量值的 ±10%** 范围内。容差写宽（如 ±20%）判 Fail；未写明判 Review。
2. 核对随机控制容差。APSD **在 500Hz 以下偏离规定要求不应超过 +3dB 或 -1.5dB；500Hz 到 2000Hz 范围内不应超过 ±3dB**；控制信号的**总均方根（grms）应控制在规定 APSD 曲线总均方根值的 +20% 和 -5% 范围内**。任一数值不符判 Fail。
3. 核对随机信号特性。随机振动信号应具有**高斯分布**，控制信号的瞬时振动加速度峰值可限制在 **3 倍 grms** 以内。开展随机振动但完全未提上述特性判 Review。
4. 核查分频带试验的说明。若随机振动试验超出振动系统功率能力，试验可分别在 **10~600Hz 和 600~2000Hz** 分频带进行，**规定的试验时间用于每个分频带**。采用分频带却缩短了单频带试验时间判 Fail。

## 08. 标准振动试验程序

- 规则编号：QTP-DO160G-08-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查标准振动的试验轴向、扫频速率、试验时长与关键频率识别是否符合标准要求。

### 审查内容

核查标准振动的试验轴向、扫频速率、试验时长与关键频率识别是否符合标准要求。

### 审查步骤

1. 核查试验曲线选择。标准振动试验曲线按设备类别与安装区域确定，按类别与区域确定；**大多数飞机类型/区域要么规定正弦、要么规定随机，仅需进行适用的一种**（飞机类型6 的第7区域可二选一）。同时安排正弦与随机且未说明依据判 Review；未说明所选曲线出处判 Fail。
2. 核对正弦程序参数。在**三个正交轴的每一轴向**进行；扫频从最低频率上扫到最高频率再下扫回最低频率，**对数扫描速率不得超过 1oct/min**；**持续时间最低 1h**。轴向数不足、扫频速率超 1oct/min、或时长短于 1h，判 Fail。
3. 核查关键频率的识别与记录。第一次上扫时记录选定响应位置的加速度曲线并确定关键频率，判据为 **(1) 峰值加速度幅值大于 2 倍输入加速度幅值的机械共振频率，或 (2) 使产品性能或行为产生明显变化的频率**（不论是否超出性能标准）；试验期间发生的关键频率变化应记录在环境合格鉴定表。缺关键频率识别判 Fail；缺记录要求判 Review。
4. 核对随机程序参数。a) 设备**非工作**状态下做 **10Hz~2000Hz、扫描速率不超 1oct/min、加速度峰值 0.5g-PK** 的正弦扫描，确定共振频率与放大系数（共振频率定义为比输入加速度幅值大两倍的响应峰值）；b) 设备**工作**状态下按性能试验量值与 APSD 谱形试验，**每轴向最低 1h**，同时对振动响应做 APSD 分析；c) 重复 a 的扫描并记录共振频率变化。三个步骤缺任一判 Fail；顺序颠倒（如先工作后扫描）判 Fail。
5. 核对试验后检查。试验完成后应对设备进行**目视检查，任何内部或外部部件均不应出现明显的结构损坏**。缺目视检查要求判 Review。

## 09. 强化振动与短时高量级振动

- 规则编号：QTP-DO160G-08-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：核查强化振动与短时高量级振动的适用性、参数与频率上限依据。

### 审查内容

核查强化振动与短时高量级振动的适用性、参数与频率上限依据。

### 审查步骤

1. 核查强化振动的曲线与轴向。曲线应按设备类别与安装区域确定，**仅需进行适用的正弦或随机试验之一**；在**三个正交轴的每一轴向**进行，扫频**对数扫描速率不得超过 1oct/min**。关键频率应按“响应峰值大于 2 倍输入加速度，或使产品性能/行为发生明显变化”的判据识别。轴向数不足、扫频速率超限或缺关键频率判据，判 Fail。检查单要求强化振动每轴试验时长 **3h**（标准振动为 1h），文档时长短于检查单要求判 Fail。
2. 核查驻留试验安排。检查单条目：是否进行驻留试验。安排驻留试验的，应说明驻留频率的选取依据（通常为关键频率/共振频率）与驻留时长；未说明依据判 Review。
3. 核查短时高量级振动的适用性与参数。使设备**处于工作状态**，按对应安装区域的量级进行正弦振动；**通用类别 H：三个正交轴每一轴向以扫描速率不超过 0.167Hz/sec、频率 10Hz~250Hz 进行 1 次正弦线性扫频**。扫描速率超 0.167Hz/sec、频率范围不符、或非工作状态，判 Fail。
4. 核查限定类别 Z 的频率上限依据。**类别 Z 可降低最高频率，但最高频率应大于等于 2 倍的最大风扇转子速率**，且最高试验频率**应正式记录在环境合格鉴定表**中。声明类别 Z 并降低了上限却未给出最大风扇转子速率或未满足 2 倍关系，判 Fail；未记录在合格鉴定表判 Review。

## 10. 振动试验判据

- 规则编号：QTP-DO160G-08-10
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：振动
- 规则说明：对应检查单「试验判据」条目与本章的性能确认要求。

### 审查内容

核查试验量级与精度符合性、功能与结构完整性判据。

### 审查步骤

1. 核查量级与精度的符合性说明。检查单要求试验量级和测试精度满足 DO-160G 第八章要求：正弦精度加速度±10%/频率±2%、正弦控制容差±10%、随机 APSD 容差（<500Hz +3/-1.5dB，500-2000Hz ±3dB）、总 grms +20%/-5%。任一项不符判 Fail。
2. 核查功能完整性判据。检查单注：应提供检查设备功能和结构完整性的方法，**电子设备应确保试验过程中设备功能正常，应明确具体检测方法**；要求在试验期间和试验结论中均确定能否符合设备性能标准。仅写「功能正常」而无检测方法判 Review；未要求过程中确认判 Fail。
3. 核查结构完整性判据。须体现「试验后目视检查，内外部件无明显结构损坏」。缺结构完整性判据判 Fail。
4. 核查显示读数的免责说明。当输入振动总位移超出 **0.5mm** 时，试件显示部件读数困难不应作为试验失败原因。文档若把振动中显示读数困难直接判为失败而未考虑该条，判 Review。
5. 若本章仅通过交叉引用说明风车振动另设独立章节，应核查引用目标存在且对应；独立风车环境章的量级、程序和记录由 QTP-WMV 规则组审查，本规则不重复输出同一问题。
