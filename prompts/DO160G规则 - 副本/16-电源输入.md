# DO-160G 第16章 电源输入 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到电源输入章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-16-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-16-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-16-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-16-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-16-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 电源输入 设备类别与试验标识

- 规则编号：QTP-DO160G-16-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：本章类别标识由「基本类别 + 试验标识字母」组成，决定做哪些子试验与取哪组限值，是全章判据的前提。

### 审查内容

核查设备类别标识是否完整、格式正确，并与设备实际供电体制一致。

### 审查步骤

1. 核查基本类别声明。**先从原文确定供电制式，再只用对应那一组类别判定，严禁把另一组的要求套上来**：
   - 设备为**直流**供电（14V/28V/270V）时，合法基本类别只有 **A、B、D、Z** 四种。大纲写「A 类」「Z 类」即为**完整合法**的基本类别声明，**判 Pass**。
     **不得**要求直流设备补充 A(CF)/A(NF)/A(WF)——那是交流设备专用的频率细分，对直流设备**不适用**（DO-160G 16.2 明文）。
   - 设备为**交流**供电时，合法基本类别只有 **A(CF)、A(NF)、A(WF)** 三种。
   - 【强制项】未声明任何基本类别，或声明的类别与供电制式不属同一组（如 28V 直流设备声明 A(WF) 类），判 Fail。
2. 核对交流类别与频率体制。**A(CF)** 指用于飞机恒频（**400Hz**）交流主电源系统；**A(NF)** 指窄变频（**360Hz~650Hz**）；**A(WF)** 指宽变频（**360Hz~800Hz**）。所选类别与文档给出的供电频率范围不一致判 Fail，并写明应为多少、实为多少。
3. 核对直流类别与电压体制。**A 类**为由交流主电源产生的直流系统中的 **28V** 直流设备（可在直流汇流条上浮置蓄电池）；**B 类**为由发动机驱动的交流发电机/整流器或直流发电机供电、且直流汇流条上**始终浮置足够容量蓄电池**的 **14V 或 28V** 直流设备；**D 类**为 **270V** 直流设备；**Z 类**为可用于其它所有类型供电系统的 **28V** 直流设备（可代替 A 类或 B 类使用）。类别与供电电压不匹配判 Fail。
4. 核查试验标识字母。**交流设备**在基本类别后附加——谐波试验做则 **H**、不需要则 **X**；电流调制试验做则 **L**、可用其它试验替代则 **Z**；功率因数试验做则 **P**、可替代则 **Z**；冲击电流试验做则 **I**、可替代则 **Z**、不需要则 **X**。**直流设备**只附加两位——电流脉动试验做则 **R**、不需要则 **X**；冲击电流试验做则 **I**、可替代则 **Z**、不需要则 **X**。
   - **直流标识合法性示例**：`AXI` = A 类（28V 直流）+ X（不做电流脉动）+ I（做冲击电流），**完全合法，判 Pass**；同理 `ARI`、`AXX`、`ZXI`、`BRX`、`DRI` 均合法。**不得**因标识中含 X 或 I 就判为「不是类别标识」「格式非法」。
   - 【建议项】只写基本类别（如「A 类」）而未附加试验标识字母时：若大纲在试验条件表或试验项目安排中**已列明**做哪些子试验（如已列出冲击电流、电流脉动的行或明确标注不开展），信息等价已具备，**判 Pass**，仅在 suggestion 中建议补齐标识字母。
   - 【强制项】既无标识字母、又无任何可据以判断子试验范围的安排（试验条件表、项目一览表、程序章均未体现），才判 Fail。
5. 核查标识字母的适用性。**仅用于交流设备的字母（H、L、P）不得标识在直流类别（A、B、D、Z）后；仅用于直流设备的字母（R）不得标识在交流类别（A(CF)、A(NF)、A(WF)）后**。【强制项】确实串用判 Fail。**注意 I、Z、X 三个字母交直流通用**，出现在直流标识中不构成串用，不得据此判 Fail。
6. 核查交直流混合供电的标识顺序。设备同时使用交流和直流电源时，标识应**先列交流类别及其全部交流试验标识，再列直流类别及其全部直流试验标识**。顺序颠倒或只列其一判 Fail。

## 07. 供电说明与工作模式

- 规则编号：QTP-DO160G-16-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：对应检查单「是否明确供电说明」「工作模式用电特性」条目。

### 审查内容

核查供电参数、工作模式用电特性与试验布置描述。

### 审查步骤

1. 核查供电说明。检查单条目：应**明确供电说明（供电为 __ VDC/VAC）**。未写明供电电压与制式判 Fail；写明电压但未区分交/直流判 Fail。
2. 核查工作模式用电特性。检查单条目：**工作模式中应明确各工作模式下的用电特性**。仅列工作模式而无各模式用电特性（功率、电流等）判 Fail。
3. 核查是否为二次用电设备。检查单条目要求说明设备是否为二次用电设备。未说明判 Review（影响试验施加点的选择）。
4. 核查试验布置描述。检查单条目：应**具备图示和（或）文字描述的试验布置要求**。完全无布置描述判 Fail。
5. 核查工作模式覆盖。检查单条目：是否**更换受试设备工作模式重复试验**。仅测单一模式而未说明理由判 Review。

## 08. 电源输入参数限值与试验项目

- 规则编号：QTP-DO160G-16-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：核查各子试验的电压、频率、持续时间等参数是否取自本类别对应的限值表。

### 审查内容

核查各子试验的电压、频率、持续时间等参数是否取自本类别对应的限值表。

### 审查步骤

1. 核查试验项目是否与类别标识对应。所声明的试验标识字母（H/L/P/I/R 等）决定应开展哪些子试验。标识为 H（做谐波试验）却未安排谐波试验，判 Fail；标识为 X（不需要）却安排了该试验，判 Review。
2. 核查正常工作状态限值。交流与直流设备分别按**正常工作**状态取稳态电压、频率、电压瞬变等限值，且须与所声明类别（A(CF)/A(NF)/A(WF)/A/B/D/Z）对应的那一组一致。文档给出的限值与本类别规定不一致判 Fail，并写明应为多少、实为多少；未给出具体限值而只写「按第16章」判 Fail。
3. 核查异常工作状态限值。交流设备和直流设备应分别采用其异常工作程序规定的电压、频率及持续时间，并与设备类别对应。缺异常工作状态试验、交直流程序混用或限值不符，判 Fail。
4. 核查应急供电系统工作。对设计为在应急供电状态下工作的设备，应安排相应的应急电压/频率条件和符合性确认。需要应急供电却未安排试验判 Fail；不适用时应说明设备功能和供电依据，无说明判 Review。
5. 核查电压/频率瞬变项目。标准规定了电压瞬变、频率瞬变（交流）、掉电（power interrupt）等试验的量值与持续时间。缺瞬变类试验判 Fail；量值或持续时间与本类别限值不符判 Fail。
6. 核查机上加载影响。规定了机上加载设备对飞机供电系统的影响（交流和直流），涉及谐波电流、功率因数、冲击电流等。声明做 H/P/I 试验却未给出对应限值判 Fail。

## 09. 电源输入试验判据

- 规则编号：QTP-DO160G-16-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：电源输入
- 规则说明：对应检查单「合格判据」条目与本章各试验的性能确认要求。

### 审查内容

核查合格判据是否可判定，并覆盖各工作状态下的性能要求。

### 审查步骤

1. 核查判据可判定性。仅写「符合设备性能标准」或「符合 DO-160G 标准」而无具体判定项，判 Review；完全未给判据判 Fail。
2. 核查判据与工作状态的对应。正常工作状态下通常要求设备**正常工作、性能不降级**；异常工作状态下允许性能降级但**不允许损坏、且恢复供电后应能自动恢复正常**。判据未区分正常/异常工作状态判 Fail。
3. 核查每次试验的符合性确认。检查单条目：应要求**在每一次试验中确定受试设备符合性能规范要求**。仅在全部试验结束后统一判定判 Review。
4. 核查偏离说明。检查单备注：若有偏离，应补充说明。存在与本章限值的偏离却无说明判 Fail。
