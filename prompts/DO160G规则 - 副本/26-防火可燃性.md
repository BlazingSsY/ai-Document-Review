## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-26-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-26-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-26-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-26-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-26-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 可燃性试验对象与试样规格

- 规则编号：QTP-DO160G-26-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：对应检查单「试验设备信息」条目与标准的试样尺寸规定。

### 审查内容

核查试验对象的零件标识与试样尺寸是否符合规定。

### 审查步骤

1. 核查零件标识。检查单条目：应**明确设备 BOM 清单中的零件名称和牌号**。仅写「非金属件」而无具体零件名称与材料牌号判 Fail。
2. 核对垂直燃烧试样。每种材料应至少取 **3 个**试样；标准矩形试样尺寸至少为 **3in×12in（75mm×305mm）**，厚度采用实际应用厚度。实际部件小于规定尺寸且无法裁取时，可用相同材料的平直薄板替代，但厚度应与飞机实际应用一致并说明代表性。数量不足、无允许条件而尺寸不足或厚度不具代表性，判 Fail。
3. 核对水平燃烧试样。每种材料应至少取 **3 个**试样；标准矩形试样尺寸至少为 **3in×12in（75mm×305mm）**，试样厚度不得超过飞机实际应用厚度且不得超过 **1/8in（3mm）**。小部件无法裁取时可采用相同材料的平直薄板，仍应满足实际厚度代表性和 3mm 上限。数量、尺寸或厚度不符判 Fail。
4. 核对 60° 电线试样。每种电线至少取 **3 根、每根长 30in（762mm）**；试样应固定形成 **24in（610mm）** 的试验段。数量、总长或试验段长度不足判 Fail。
5. 核查状态调节和试样标识。应说明各试样的材料/牌号、实际应用厚度和编号；试样应在 **21℃±3℃、相对湿度 50%±5%** 条件下存放至少 **24h**，试验前从存放环境中迅速取出且每次只取一个。缺状态调节条件/时长或导致试样代表性无法确认，判 Fail。

## 07. 可燃性试验实施

- 规则编号：QTP-DO160G-26-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：对应检查单「试验实施」条目与标准的试验程序。

### 审查内容

核查试验方法、点火时间、防耐火试验的位置分析与温度校准。

### 审查步骤

1. 核查试验方法与点火时间。可燃性试验应明确所采用的方法和点火时间：**垂直燃烧试验施焰 12s，水平燃烧试验施焰 15s，60° 电线本生灯试验施焰 30s**。未写明方法、缺点火时间或数值与对应方法不符，判 Fail。
2. 核查防耐火试验的火焰冲击位置分析。检查单条目：防耐火试验应**进行火焰冲击位置和试验工况分析**。未给出火焰作用位置的选取依据判 Fail。
3. 核查温度校准程序。检查单条目：防耐火试验**必须有温度校准程序**。缺温度校准程序判 Fail（无校准则火焰温度不可信，试验结论无效）。
4. 核查试验程序是否符合标准。程序描述应可追溯到标准相应条款。仅写「按 DO-160G 进行」而无具体程序判 Review。

## 08. 可燃性试验判据

- 规则编号：QTP-DO160G-26-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：对应检查单「试验判据」条目给出的三类燃烧试验判据。

### 审查内容

核查各燃烧试验方法的合格判据数值是否齐备且正确。

### 审查步骤

1. 核对垂直燃烧试验判据。所有受试试样的**平均燃烧时间不得超过 15s，滴落物的平均燃烧时间不得超过 5s，平均燃烧长度不得超过 8in（203mm）**。缺少任一指标或限值不符判 Fail。
2. 核对水平燃烧试验判据。所有受试试样的**平均燃烧速度不得超过 4in/min（约 102mm/min）**。缺少数值判据或限值不符判 Fail。
3. 核对 60° 电线本生灯试验判据。所有受试试样的**平均燃烧/熄灭时间不得超过 30s，滴落物的平均燃烧时间不得超过 3s，平均燃烧长度不得超过 3in（76mm）**；试验中导线断裂本身不构成失败。缺少任一指标、误将导线断裂直接判失败或限值不符，判 Fail。
4. 核查判据与所采用方法的对应。文档采用了某种燃烧试验方法却给出另一种方法的判据，判 Fail。
5. 核查判据可判定性。仅写「符合 DO-160G 标准」而无上述数值判 Review。

## 09. 可燃性分析与豁免

- 规则编号：QTP-DO160G-26-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：防火可燃性,可燃性
- 规则说明：对应检查单「分析/报告」条目。可燃性试验对象由分析确定，分析缺失会导致漏试。

### 审查内容

核查可燃性分析报告、BOM 逐项分析与豁免方法的正确使用。

### 审查步骤

1. 核查前置分析报告。检查单条目：可燃性试验大纲的前置**应有用于支持可燃性试验对象选取的设备可燃性分析报告**。未提及该分析报告判 Fail（无分析则试验对象的选取无依据）。
2. 核查 BOM 逐项分析。检查单条目：应**按 BOM 清单逐一分析各零组件是否能满足可燃性要求，并列出需开展试验的零件清单**。未按 BOM 逐项分析判 Fail；有分析但未输出需试验零件清单判 Fail。
3. 核查豁免方法的正确使用。检查单条目：应**正确使用豁免方法进行分析**，例如「各面由金属构成或包围且没有通风孔」这类结构豁免条件。使用豁免但未说明所依据的具体豁免条件判 Fail；豁免条件与零件实际结构明显不符判 Fail。
4. 核查分析与试验的一致性。分析得出的需试验零件清单，应与大纲中实际安排的试验对象一致。清单中的零件未安排试验且无豁免说明，判 Fail。
