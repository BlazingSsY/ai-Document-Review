# DO-160G 第21章 射频能量发射 试验大纲审查规则

> 规则类型统一为 `test_item_chapter`，按关键词收敛到射频发射章。
>
> 本文件第 1～5 条规则来源于《QTP检查单-全部规则-PDDS》“测试设备/系统”组，必须在当前试验章节逐条执行并分别返回结果；不得合并或省略。若本试验项目明确不适用且给出了充分依据，仍必须返回审查结果并注明不适用依据，不得省略该规则。

## 01. 本章测试设备名称及型号

- 规则编号：QTP-DO160G-21-01
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查当前试验章节是否明确列出全部测试设备的名称及型号。

### 审查内容

核查本章使用的测试设备是否逐台给出名称及型号，并与试验程序中实际使用的设备相互对应。

### 审查步骤

1. 核查测试设备清单。当前章节应列出本试验使用的全部测试设备名称及型号；完全未提供测试设备信息判 Fail。
2. 核查逐台完整性。每台设备均应同时具有可识别的名称和具体型号；仅写“温箱”“振动台”“示波器”等通用名称而无具体型号，或名称/型号填写为 `XXX`、`TBD`、`待定`、`待补充`等占位文本，均判 Fail，并逐台列出缺失项。填写 `N/A`、`/`、`-` 只能表示该字段不适用；若未同时说明设备确无型号及可核验理由，不得据此判 Pass。
3. 核查与程序的对应。试验程序中使用的仪器、传感器、探头、信号源、负载或数据采集设备应能在设备清单中找到；程序使用但清单未列出的设备判 Fail。
4. 若本试验明确无需专用测试设备，必须给出可核验的原因；理由充分时判 Pass 并注明不适用依据，仅写“不适用”而无理由判 Review。

## 02. 本章测试设备完整性

- 规则编号：QTP-DO160G-21-02
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查当前章节列出的测试设备是否足以完成本章试验、监测和判定任务。

### 审查内容

核查测试设备配置能否覆盖本章的环境施加、参数控制、状态监测、性能测试、数据采集和安全防护需求。

### 审查步骤

1. 根据本章试验条件和程序识别必须具备的设备功能，包括环境/载荷产生与控制、参数测量、受试设备监测、功能性能测试和数据记录等。
2. 建立“本章必需功能—程序中承担该功能的设备—设备清单条目”的逐项对应关系，并在判定理由中列出对应结果；缺少完成任一必需功能的设备，设备清单与程序明显不一致，或只用占位文本表示设备，均判 Fail，并说明缺少的设备功能。不得仅凭设备表“看起来种类较多”推断配置完整。
3. 若仅凭章节现有信息无法确认设备是否满足试验要求，判 Review；不得在没有设备能力证据时直接判 Pass。

## 03. 本章测试设备关键参数

- 规则编号：QTP-DO160G-21-03
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查测试设备的关键参数是否明确并覆盖本章试验要求。

### 审查内容

核查每台关键测试设备是否给出与本章试验相关的量程、精度、分辨率、频率范围、带宽、采样率、功率或环境能力等参数。

### 审查步骤

1. 按设备用途识别应描述的关键参数，并逐台核查；关键参数完全未描述或缺少决定试验能力的参数判 Fail。
2. 必须逐台形成“设备/用途—本章试验要求（范围、量级、允差等）—设备声明能力—比较结论”的证据链。不能只因设备表列出了若干精度或量程就判 Pass；应实际比较两侧数值与单位。设备能力不能覆盖要求判 Fail，并列出“设备能力—本章要求”的差异；两侧信息齐全且逐项满足方可判 Pass。
3. 涉及多点测量时，核查传感器数量和布置；涉及冲击、电压尖峰或雷电瞬态等瞬态量时，核查采样率、带宽和存储能力。适用但未说明判 Fail。
4. 已检索本章试验条件、程序及设备表后，仍缺少设备能力或试验要求中的任一侧，判 Review 并指出待补证项；参数因图表不可读或解析缺失而无法确认时也判 Review，不得省略本规则结果。

## 04. 本章测试设备校准周期与有效期

- 规则编号：QTP-DO160G-21-04
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查测试设备的校准周期/有效期及试验时校准状态要求。

### 审查内容

核查当前章节是否说明测试设备的校准周期或校准有效期，并要求试验实施时设备处于有效校准状态。

### 审查步骤

1. 逐台核查承担测量、控制和数据采集任务的设备是否给出可核验的校准有效性依据，例如“校准周期＋最近校准日期”、明确的有效期截止日期，或可追溯到试验日期的校准证书信息；完全缺失判 Fail。
2. 仅填写“定检”“设备校验”“已校准”“检定合格”等泛化状态，既无周期/有效期又无法确认试验实施日在有效期内时，判 Fail，不得当作有效校准证据；只列周期但未约束或无法核验试验时状态判 Review。
3. 本章若有试验前校准或波形验证等专门要求，还应核查该要求是否落实；适用但缺失判 Fail。
4. 校准信息位于不可读附件或解析缺失区域时判 Review，并指出待复核位置。

## 05. 本章测试设备精度/量程替代方案

- 规则编号：QTP-DO160G-21-05
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查测试设备替代条件是否明确限定为精度、量程等同或更优。

### 审查内容

核查当前章节是否明确测试设备替代方案，以及替代设备的精度、量程和其他关键能力不得低于原设备。

### 审查步骤

1. 核查是否给出设备替代准入条件：只有替代设备的精度、量程及相关关键能力等同或优于原设备时，才允许更换。完全未规定替代方案判 Review。
2. 有设备更换条款但未限定“等同或更优”，或允许使用能力更低的设备，判 Fail。
3. 核查替代后是否仍满足本章试验范围、允许误差及校准有效性要求；无法证明时判 Review。
4. 【建议项】试验记录中写明替代设备、替代理由和能力对比，属推荐做法。有替代条款而无记录要求时仍判 Pass，仅在 suggestion 中建议补充记录要求，不判 Review、不计入 missing_items。

## 06. 射频能量发射 设备分类

- 规则编号：QTP-DO160G-21-06
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：本章类别由设备与飞机无线电天线的相对位置和间隔距离决定，决定取哪条发射限值曲线。

### 审查内容

核查类别声明及其与设备安装位置的对应关系。

### 审查步骤

1. 核查类别声明。类别**根据设备与飞机无线电天线之间的相对位置和间隔距离来确定**。未声明类别判 Fail。
2. 核对类别语义与安装位置。**B类**——干扰应被控制在可承受电平范围内的设备；**L类**——位于**远离飞机开口（如窗口）和无线电接收机天线区域**的设备及互连电缆（适用于电子舱）；**M类**——位于**存在明显电磁环境的开口处、但不直接暴露于无线电接收机天线区域**的设备及互连电缆（适用于运输类飞机客舱或座舱）；**H类**——**直接暴露于无线电接收机天线区域**的设备（典型为飞机外部设备）；**P类**——位于靠近**高频、甚高频（VHF）或全球定位系统（GPS）**接收机天线区域，或飞机结构几乎不能提供屏蔽的设备及互连电缆；**Q类**——位于靠近 **VHF 或 GPS** 接收机天线区域，或飞机结构几乎不能提供屏蔽的设备及互连电缆。所选类别与文档描述的安装位置矛盾判 Fail；未说明安装位置判 Review。
3. 核查天线端子乱真信号的排除。**本章不对由接收机或发射机天线端子传导出的乱真信号进行测量或抑制**，该抑制应在接收机/发射机设备性能规范中规定。把天线端子乱真信号纳入本章试验判 Review。
4. 核查非发射模式的要求。当无线电发射机或接收/发射机处于**非发射或接收模式**时，**必须满足规定的发射要求**（包括相邻通道之间频带的 **±50% 选择频率**）。含收发功能的设备未说明非发射模式下的发射要求判 Fail。

## 07. 射频传导发射试验

- 规则编号：QTP-DO160G-21-07
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查频率范围、测量装置、限值曲线选取与电流探头位置。

### 审查内容

核查频率范围、测量装置、限值曲线选取与电流探头位置。

### 审查步骤

1. 核对频率范围。**传导发射测量频率范围为 150kHz~152MHz**。范围不符或未写明判 Fail，并写明应为多少、实为多少。
2. 核对测量装置。应使用**卡钳式干扰测量装置**来测量设备产生的干扰电流。测量装置类型不符判 Fail。
3. 核对电源线限值。任何与飞机汇流条连接的 **EUT 电源线**上的发射电平不应超出所声明类别对应的**传导发射限值曲线**。限值来源不明判 Fail。
4. 核对互连电缆限值。**EUT 任何互连电缆束**上的发射电平不应超出所声明类别对应的**传导发射限值曲线**；**主电源线不视为互连电缆束**；**处于非发射或接收工作模式的天线馈电电缆可视为互连电缆**。把主电源线按互连电缆限值判定判 Fail。
5. 核对电流探头位置。**电流探头安装在距离 EUT 5cm 处**；若 EUT 连接器和基座的总长度超过 5cm，**监测探头应尽量靠近机箱连接器的基座，并记录探头位置**。距离不符或未写明判 Fail；超长情形未规定记录探头位置判 Review。
6. 核查测试布置。大纲应以图示或文字给出电流探头的测试布置。缺布置描述判 Fail。
7. 核查限值曲线的类别对应。应测量并记录 EUT 发射电平，并使用**所声明类别对应的适用限值曲线**。使用了与所声明类别不符的限值曲线判 Fail。

## 08. 射频辐射发射试验

- 规则编号：QTP-DO160G-21-08
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查频率范围、限值曲线、天线极化、场强换算与 EUT 开口朝向。

### 审查内容

核查频率范围、限值曲线、天线极化、场强换算与 EUT 开口朝向。

### 审查步骤

1. 核对频率范围。**辐射发射测量频率范围为 100MHz~6000MHz**。范围不符或未写明判 Fail，并写明应为多少、实为多少。
2. 核对限值曲线。从设备任何装置、电缆或互连线辐射出的干扰场不应超出**所声明类别对应的辐射发射限值曲线**。限值来源不明或与类别不符判 Fail。
3. 核对场强换算方法。通过使用适当天线，将**相应的天线系数与测量电压（dBμV）相加**得到测量场强；**还必须加上电缆损耗和匹配网络的校准系数**。未说明换算方法判 Review；漏算电缆损耗/匹配网络系数判 Fail。
4. 核对天线极化。**辐射测试必须使用线极化天线**；辐射发射测量应使用**垂直和水平两个极化方向**。使用非线极化天线判 Fail；只做单一极化判 Fail。
5. 核查 EUT 开口朝向要求。应**直接将 EUT 的开口（例如显示器、CRT、连接器）暴露于接收天线前**，这可能需要增加 EUT 方向或调整接收天线位置；**若未将 EUT 的所有开口暴露于接收天线之前，必须在试验报告中给出合理的理由**。未说明开口朝向安排判 Fail；未全部暴露且无理由说明判 Fail。
6. 核查最大发射工作模式。**应考虑 EUT 产生最大发射的实际工作模式**。未说明所测模式为最大发射模式判 Fail（检查单同样要求说明工作模式的选取与确认方式）。
7. 核查试验布置。大纲应以图示或文字给出射频辐射发射试验设备的布置。缺布置描述判 Fail。

## 09. 混响室法与试验布置通用要求

- 规则编号：QTP-DO160G-21-09
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：核查所选试验方法一致性、供电、搭接与线束信息。

### 审查内容

核查所选试验方法一致性、供电、搭接与线束信息。

### 审查步骤

1. 核查试验方法的选择。标准提供常规辐射发射法与**混响室法**两种。文档应明确采用哪一种并全程一致。未说明所采用方法判 Fail；混用两种方法参数判 Fail。
2. 核查混响室法的特有要求。采用混响室法时应说明搅拌器/调谐器设置、室内场均匀性验证与校准方法。声明混响室法却套用常规法的天线极化/距离描述判 Fail。
3. 核查供电说明。检查单条目：应**明确供电说明（供电为 __ VDC/VAC）**。未写明判 Fail。
4. 核查电搭接与接地信息。检查单条目：应具备**电搭接和接地信息（图示或文字描述）**，并参照机上安装方式。缺失判 Fail。
5. 核查线束信息。检查单条目：应说明线束**型号和连接器型号、线缆长度、屏蔽方式**等，并说明与机上是否一致。缺失判 Fail；未说明与机上一致性判 Review。
6. 核查试验布置描述。检查单条目：应**具备图示和（或）文字描述的试验布置要求**。缺失判 Fail。
7. 核查通用接地平板与电缆布置。接地平板应为紫铜、黄铜或铝，紫铜/铝厚度至少 **0.25mm**、黄铜至少 **0.5mm**，深度至少 **0.75m**、面积至少 **2.5m²**；电缆束通常支撑在平板上方 **50mm**，互连电缆至少 **3.3m**，EUT 引出电缆至少 **1m** 平行布置在距试验台前沿 **10cm** 处。偏离装机代表性或上述标准布置而无依据判 Fail。
8. 核查 LISN 与电源回线。每根主电源线应按标准配置 LISN，外壳搭接至接地平板，射频端口端接 **50Ω**；自谐振频率高于 **10kHz** 的 LISN，每个电源输入端至接地平板并接 **10μF** 电容。就近固定于接地平板的电源回线不要求测试。配置或排除范围不符判 Fail。
9. 核查测量接收机设置。应使用**峰值检波**，中频/分辨率带宽按频段设置为：0.15～30MHz 为 **1kHz**，30～400MHz 为 **10kHz**，0.40～0.96GHz 为 **100kHz**，0.96～6GHz 为 **1MHz**；峰值检波器时间常数应不大于 **1/BW**，视频带宽应不小于分辨率带宽。检波方式或带宽不符判 Fail。
10. 核查扫描与数据分辨率。每个频段最小驻留时间均为 **0.015s**；模拟接收机最小测量时间分别为：0.15～30MHz **0.015s/kHz**、30～400MHz **1.5s/MHz**、0.40～0.96GHz **0.15s/MHz**、0.96～6GHz **15s/GHz**；混响室法在 100～400MHz 的最小扫描时间为 **9s**，0.40～6GHz 各频段为 **1s**。综合接收机步长应为 **1/2 带宽**。具有“最大保持”功能的接收机或频谱分析仪可进行多次快速扫描，但累计扫描必须满足上述最小测量时间。记录数据的频率分辨率至少为 **1% 或两倍接收机带宽（取较宽者）**，幅度分辨率至少 **1dB**，幅频曲线应自动生成且连续。缺时间、步长或数据分辨率要求判 Fail。

## 10. 射频能量发射试验判据

- 规则编号：QTP-DO160G-21-10
- 规则类型：试验项目章节
- 文档类型：环境鉴定试验大纲
- 关键词：射频能量发射
- 规则说明：对应检查单「合格判据」条目与本章的限值符合性要求。

### 审查内容

核查限值数据、超标处置与工作模式覆盖。

### 审查步骤

1. 核查限值与实测数据的呈现。应给出**所选类别的限值曲线与实测发射电平的幅-频数据**，二者可对照判定。缺限值或缺实测数据判 Fail。
2. 核查判据表述。发射类试验的判据是「**发射电平不超出适用类别的限值**」。判据写成「设备工作正常」而不涉及限值判 Fail。
3. 核查超标处置。出现超标频点时应规定记录方式与处置（如复测、加装滤波、申请偏离）。未规定判 Review。
4. 核查工作模式覆盖。检查单条目：应覆盖产生最大发射的实际工作模式，并说明如何确认。仅测单一模式且未说明其为最大发射模式判 Fail。
5. 核查判据可判定性。仅写「符合 DO-160G 标准」而无限值依据判 Review；完全未给判据判 Fail。
6. 核查试验记录要求。应至少记录：每根电缆束的长度、类型、屏蔽/端接和接线图；试验配置框图或照片、线束/探头/天线位置与 EUT 搭接；EUT 工作模式；全部实际/模拟负载及阻抗范围；测量接收机设置、天线系数、电缆损耗、校准数据、完整实测幅频曲线、超标处置和结论。缺少足以复现试验或支持限值判定的关键记录项判 Fail。
